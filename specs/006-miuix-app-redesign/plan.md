# 全应用 Miuix 界面实施计划

## 设计

参考 SukiSU Nova 的大标题、分组卡片和紧凑设置行，为校园应用保留课程、考试、邮件和资讯各自的数据结构。手机底栏保留液态玻璃，宽屏使用实色侧栏。页面采用 MiSans、低对比背景和少量语义强调色。

## 实现

在 Flutter 3.44.2及以上通过 `flutter_miuix` 主题控制器生成统一配色。在现有清源门面内替换通用视觉实现，保留按钮、编辑器、导航与弹层对业务页面的接口。外观开关独立存储于本地设置。

## 验证

核对应用入口和详情覆盖范围，运行格式检查、静态分析、真实控件测试和本地配置读写测试，检查 Windows 构建。
