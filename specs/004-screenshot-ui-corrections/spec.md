# Feature Specification: Screenshot-driven UI corrections

**Feature Branch**: `bugfix/screenshot-ui-corrections`
**Created**: 2026-09-12
**Status**: Draft
**Input**: 修正截图中首页、教务、课表、信息、邮箱与快速跳转页面的展示和数据问题。

## User Scenarios & Testing

### User Story 1 - 清晰查看校园首页 (Priority: P1)
用户打开首页即可看到只包含课程、考试和待办的今日时间轴，并能正确看到培养方案状态及均匀排列的校园服务卡片。

**Independent Test**: 使用固定夹具渲染首页，在桌面与移动宽度检查时间轴条目、培养方案状态和卡片间距。

**Acceptance Scenarios**:
1. Given 首页存在资讯公告，When 查看今日时间轴，Then 时间轴不显示资讯公告。
2. Given 培养方案有已读/未读状态，When 加载首页，Then 卡片展示与数据源一致。

### User Story 2 - 准确浏览教务与课表 (Priority: P1)
用户可在教务概览和课程/考试页看到统一对齐的指标、正确的全量成绩统计和夏季学期/补考数据，并区分本周与整学期。

**Independent Test**: 使用夏季学期和春季补考夹具渲染页面并核对统计、学期切换和课程周次。

**Acceptance Scenarios**:
1. Given 多学期成绩，When 查看教务概览，Then 平均绩点与已获学分按全部相关成绩计算且各指标对齐。
2. Given 当前为夏季学期，When 查看考试，Then 显示夏季考试及上一学期补考，并可切换学期。
3. Given 查看整学期，When 切换视图，Then 展示整学期课程而非仅当前周。

### User Story 3 - 高密度浏览信息与邮箱 (Priority: P1)
用户可以在有限屏幕中浏览信息来源、分页和邮件列表/详情，不被统计行、解析错误或溢出打断。

**Independent Test**: 在 360、768、1200、1600 宽度渲染信息和邮箱页面。

**Acceptance Scenarios**:
1. Given 信息页有多个来源，When 查看页面，Then 无顶部统计行，来源面板与列表对齐，分页不截断。
2. Given 邮件无正文，When 打开详情，Then 显示空态而非解析错误，副标题被移除。

### User Story 4 - 响应式快速跳转 (Priority: P2)
用户在宽屏看到多列分类卡片，中等宽度看到两列，窄屏看到单列且入口可点击。

**Independent Test**: 使用三种断点截图比对分类卡片列数及内容完整性。

## Edge Cases
- 仅有一个来源、无资讯或无邮件正文。
- 夏季学期无考试或上一学期无补考。
- 屏幕宽度不足以容纳两列时必须自动降为单列。
- 成绩/学分为空或包含重复课程时不应显示错误数值。

## Requirements

### Functional Requirements
- **FR-001**: 首页时间轴 MUST 仅包含课程、考试和待办条目。
- **FR-002**: 首页培养方案状态 MUST 映射真实已读/未读数据，校园服务卡片间距 MUST 随宽度自适应。
- **FR-003**: 教务概览 MUST 删除无要求的状态标签、详细数据源及考试/成绩详情卡，并将身份、概览和下一场考试整合为对齐布局。
- **FR-004**: 教务指标 MUST 使用全部相关成绩计算平均绩点、已获学分和已读成绩，并保持统一尺寸。
- **FR-005**: 课程/考试 MUST 支持夏季学期当前考试、上一学期补考和明确的学期切换；整学期视图 MUST 展示完整课程。
- **FR-006**: 信息页 MUST 移除统计行，来源面板与列表对齐，资讯卡片和分页区域 MUST 响应式且不溢出。
- **FR-007**: 邮箱页 MUST 移除只读快照副标题，仅显示时间/标题/发件人；无正文邮件 MUST 使用空态而非解析错误。
- **FR-008**: 快速跳转分类卡片 MUST 按宽度采用多列、两列或单列布局。
- **FR-009**: 所有修改 MUST 遵循 Qingyuan facade 与设计令牌，并通过桌面、平板、移动渲染验证。

### Key Entities
- **AcademicTerm**: 学期及其课程、考试和补考关系。
- **AcademicGradeSnapshot**: 成绩记录、绩点、学分和读取状态。
- **InfoSource/InfoMessage**: 信息来源与资讯条目。
- **EmailMessageSnapshot**: 邮件元数据、正文和空态状态。

## Success Criteria
- **SC-001**: 六个页面在 360×800、768×900、1200×900、1600×1000 下无底部溢出或横向裁切。
- **SC-002**: 首页时间轴不再出现资讯公告，教务多学期夹具的平均绩点和学分计算正确率达到 100%。
- **SC-003**: 课表/考试夹具可同时呈现夏季考试与上一学期补考，整学期课程数量与数据源一致。
- **SC-004**: 信息分页、邮箱列表和详情在目标尺寸内可滚动且无“解析错误”误报。
- **SC-005**: 快速跳转在宽屏为至少三列、中屏两列、窄屏单列。

## Assumptions
- 现有数据服务和 Qingyuan 组件继续复用，不新增外部依赖。
- 补考统一关联上一个教学学期；无补考时显示友好空态。
- 视觉验证使用现有固定夹具和截图采集入口。
