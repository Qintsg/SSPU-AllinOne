# UI Contract: 校园工作台响应式收敛

## 响应式断点契约

- 控件根据 `LayoutBuilder` 提供的真实内容宽度决策，不用未扣除边距的外层窗口宽度替代。
- 宽屏优先横向并列或网格；宽度不足时切换为单栏或换行。
- 360×800、768×900、1200×900 目标窗口均不得产生 `RenderFlex overflow`。

## 教务

- 单一聚合概览包含五项身份字段和核心指标。
- “完成度”“学习档案”“查看详细数据来源”不可见且不可被语义树命中。
- 下一场考试与概览宽屏对齐、窄屏按阅读顺序堆叠。

## 信息

- 来源固定为“全部”“官网”“微信公众号/服务号”。
- 顶部刷新触发所有启用渠道。
- 分页切换后列表滚动位置归零；分页可换行且不越界。

## 邮箱

- 桌面列表和详情同屏并独立滚动；移动端列表进入独立详情。
- 列表行只展示时间、标题、发件人。
- 正文保留段落且不创建远端内容请求。
- `email-search-field` 和旧说明文案不存在。

## 课表、导航与工具

- 桌面周视图按星期和节次定位课程块，左侧显示节次/时间；移动端按天列表。
- 快速链接 tile 横向排列并换行。
- AI 配置宽屏为窄/宽等高双栏，窄屏单栏；服务按钮紧邻端口输入。
- 桌面设置固定在导航轨底部，destination 索引不变。
