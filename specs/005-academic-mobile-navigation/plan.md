# 实施计划：新版教务前端与移动导航

## Technical Context

Flutter 3.44.2及以上、Dart 3.12.2及以上、`flutter_miuix` 1.3。通过清源门面提供 Miuix 组件封装，页面继续使用已配置的应用主题、图标与语义令牌。

## Constitution Check

用户指定 Miuix 作为该范围的组件风格。依赖限于设计组件层，数据层继续使用现有的只读接口、安全存储及学期模型。业务状态和路由由现有页面持有。

## Layout

- 移动端在安全区上方放置玻璃胶囊，主内容和玻璃分别位于采样层与前景层，保留内容末尾的操作空间。桌面继续使用既有导航。
- 教务使用清源背景、表面、学业蓝、前景与辅助文本语义色，沿用系统中文字体。总览由身份及指标区、考试区、常用查询和校园活动组成。窄屏由上至下阅读，宽屏的指标与考试并排。
- 详情页用简明标题、可见操作和任务正文组成统一框架，保留专用表格和筛选控件。

## Verification

运行 Dart 格式检查、全仓静态分析、Spec Kit 校验以及覆盖真实导航树和空状态的 Flutter 测试。通过已登录新版教务页面核验学籍和确认可用的官方查询入口。
