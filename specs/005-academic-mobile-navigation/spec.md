# 功能规格：新版教务前端与移动导航

**工作分支** `refactor/353-academic-system`

**日期** 2026-11-19

**相关议题** #353

## User Scenarios & Testing

### US1 — 移动端单手切换页面（P1）

手机用户通过悬浮液态玻璃底栏切换主页、教务、课表和信息，并从“更多”访问其余页面。桌面用户沿用侧栏或窄窗口导航。

- 已打开教务时，底栏选中教务。打开更多面板再取消时，当前页仍为教务。
- 点击更多面板内的目的地时，页面与底栏选中状态一起更新。
- 使用手势区域或放大字体时，内容末尾和底栏均能访问。

### US2 — 快速查阅教务（P1）

学生在一屏内找到常用查询，能区别学籍与学业数据、缓存与读取异常，并进入课表、考试、成绩、培养方案及可用查询页面。

- 学籍概览显示已经读取的字段，成绩不可用时不显示虚构的零分或零学分。
- 体育考勤和第二课堂继续使用各自数据源，在校园活动区可独立进入详情。
- 只显示确认可用的官方查询入口。账号、角色和站点更新造成的未确认状态不直接视为功能下线。

### US3 — 在窄屏和宽屏阅读详情（P2）

详情页将标题、返回、刷新与主要内容置于同一阅读流。课表保留既有学期与视图切换，成绩、考试和培养方案保留各自筛选、缓存和错误提示。

## Requirements

- **FR-001** 移动端导航使用悬浮底栏和液态玻璃，主题跟随应用设置。桌面窗口使用原有无玻璃导航。
- **FR-002** 教务概览重组学籍、指标、下一场考试、查询入口和校园活动。查询项有明确点击去向。
- **FR-003** 教务详情使用一致的页面样式，保留正常、加载、空结果、缓存和失败状态。
- **FR-004** 校园系统交互保持只读，学籍字段仍走账号校验与加密缓存。

## Success Criteria

- **SC-001** 在320和390逻辑像素宽的移动布局可通过底栏访问所有目的地，桌面宽屏通过侧栏访问。
- **SC-002** 在移动窄屏和桌面宽屏打开教务首页与详情时，无横向裁切，底部内容可滚动到达。
- **SC-003** 使用真实教务页面验证学籍解析和已纳入前端的新版官方入口。
