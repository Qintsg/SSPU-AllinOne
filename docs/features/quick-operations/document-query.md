## 1. 需求

汇总常用文档、办事流程说明与规章制度（规则）等，提供统一查询入口：按类别浏览、关键词搜索、预览/下载、收藏/置顶。覆盖 #131「常用办事流程和文档汇总」。

**验收要点**
- 按类别分组展示文档/流程条目，条目含标题、描述、来源、链接/下载。
- 关键词搜索（标题/描述）。
- 文档可预览（内置 WebView），下载型 URL 交系统/外部。
- 可收藏/置顶常用条目。
- 空状态与加载失败状态有明确提示；适配桌面/移动。

## 2. 数据来源（内置 YAML 汇总）

沿用 `quick_links.yaml` 同类的内置配置模式，新增文档汇总配置：

```yaml
doc_groups:
  - category: 规章制度
    items:
      - title: <文档名>
        desc: <简要说明>
        source: <来源单位/出处>
        url: <链接或下载地址>
        kind: web | download        # 预览 or 下载
```

- 条目随版维护（本期不做远程下发）；类别如 教务 / 学工 / 规章制度 / 办事指南 等。

## 3. 实现

### 3.1 浏览与搜索

- 按 `category` 分组浏览；关键词在 `title`/`desc` 本地匹配。

### 3.2 预览与下载

- `kind: web` → 内置 WebView 预览（带外部浏览器按钮）。
- 下载型 URL（PDF/doc/压缩包等）→ **交系统下载或外部应用打开**，复用 [info 的下载型 URL 处理](../info/message-center.md)。

### 3.3 收藏 / 置顶

- 收藏与置顶状态**本地持久化**（系统默认应用数据目录），用于快速访问与排序。

## 4. 关联

- 关联：[快捷跳转](quick-jump.md)（办事入口与文档互补，同模块）。

- 依赖：[本地存储](../platform/system/storage-sync.md)（收藏/置顶）。

## 5. 约束

- 文档来源为公开链接/下载，只读汇总；不代理登录态。
- 下载型 URL 交系统/外部处理，避免在 WebView 内异常。
- 数据全本地（含收藏/置顶），不上云；来源需可信、明确。
