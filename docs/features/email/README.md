# 邮箱（Email）

> 业务域：`email`　·　所属：[功能总览](../README.md)

## 1. 模块职责

提供学校邮箱的收发：收件箱浏览/阅读（含分页、已读未读、搜索、附件查看）与撰写发送（纯文本 + 附件）。账号固定 `学工号@sspu.edu.cn`，使用独立邮箱密码，走公网腾讯 exmail 端点，**无校园网门禁**。

## 3. 内部依赖

- 依赖：[登录与凭据](../academic/auth-credentials.md)（独立邮箱密码）、[本地存储](../platform/system/storage-sync.md)（缓存/附件）、[后台自动刷新](../platform/system/auto-refresh.md)。
- 两功能共享账号、端点与凭据基座。

## 4. 模块级约束

- **协议边界**：IMAP/POP 收信、SMTP 发信；SMTP 不能收信。
- **收信只读 + 一处例外**：唯一服务器写操作为 IMAP `\Seen` 已读回写（用户动作触发）；不提供删除、移动、批量、自动回复/转发。
- **发信仅用户主动**：不自动发送、不后台重试、不撤回；发信明文不入日志与普通缓存。
- 凭据进系统安全存储；缓存/附件存系统默认应用数据目录，按账号隔离；敏感信息不进日志。
