# 校园网（Network）

> 业务域：`network`　·　所属：[功能总览](../README.md)
>
> 本模块为重新规划版本，**不沿用旧前端实现**（前端重构中）。服务/状态模型为设计真源。

## 1. 模块职责

统一感知与处理设备的校园网络环境，并作为受限校园服务（教务、校园卡、邮箱等）的**访问门禁**：

- **状态检测**：判定当前网络环境（6 态），作为全局门禁与顶栏/主页展示的共享数据源。
- **网络诊断**：对内网各服务逐项体检并测速，辅助排障。
- **VPN 一键连接**：**仅桌面**，由用户手动置入本地 `plugins/` 的 VPN 插件提供连接能力，应用编排状态与策略。
- **本地插件机制**：扫描应用目录 `plugins/` 加载插件并暴露「添加组件 / 执行文件」方法，当前仅服务 VPN。**应用内不提及插件/来源。**

## 3. 内部依赖

- 状态检测、诊断、VPN 共享同一份**网络状态**（6 态，见 `network-status.md`）。
- VPN **依赖** [本地插件机制](plugin-host.md) 获取连接能力（仅桌面）；状态检测读取 VPN 插件隧道态以区分 `vpnPlugin` / `vpnExternal`。
- **被依赖**：教务 / 校园卡 / 邮箱等受限服务在请求前调用门禁（前置检查 + 按策略自动连 VPN）。

## 4. 网络状态模型（6 态）

| 状态 | 含义 | 可达受限服务 | 可开启 VPN（仅桌面） |
| --- | --- | --- | --- |
| `offline` 离线 | 无任何网络连通 | 否 | 否 |
| `campus` 校园网直连 | 处于校园网内 | 是 | 否（无需） |
| `vpnExternal` VPN·外部 | 经系统/自建 VPN 已可达校园 | 是 | 否（尊重现有连接） |
| `vpnPlugin` VPN·插件 | 经本地 VPN 插件建立的隧道 | 是 | 已连接 |
| `outsideUnconnected` 校外·未连接 | 有外网但校园服务不可达 | 否 | 是（VPN 入口可达时） |
| `unknown` 检测中/未知 | 尚未完成或无法确定 | 否 | 否 |

> `vpnPlugin` 仅桌面可能出现；移动端无 VPN 能力。

## 5. 模块级约束

- **应用内 UI/文案零提及**插件、`plugins` 目录、外部来源或仓库（仅设计文档记录机制）。
- **门禁优先、网络探测不阻塞 UI**：检测异步，首检前为 `unknown`，不误报。
- **VPN 仅桌面、进程隔离**：应用不下载/不分发/不内嵌插件产物，由用户手动置入；独立进程运行使许可证（如 AGPL）保持隔离。
- **敏感信息零泄漏**：账号、密码、token、cookie、VPN 会话不进日志、状态文件、Release notes 或测试 fixture。
- 探针可注入，测试用 fake，不访问真实 `vpn.sspu.edu.cn` 与真实 VPN 账号。
