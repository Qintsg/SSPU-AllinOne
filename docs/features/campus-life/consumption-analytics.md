## 1. 需求

基于校园卡交易明细，提供**只读**的消费时间趋势可视化，帮助用户直观了解一段时间内的消费变化。

**验收要点**
- 以**单个时间趋势图（柱状/折线）**展示消费金额随时间的变化。
- 支持选择时间窗（如近 7 天 / 近 30 天 / 自定义区间）。
- 纯本地计算，不额外联网；无可用明细时给出空态。
- 只读分析，**不涉及任何写操作**。

## 3. 交互与界面（期望行为，前端重构后落地）

- 一张时间趋势图（柱状或折线），X 轴为时间桶（按日/周/月，依时间窗自动选择），Y 轴为消费金额。
- 时间窗切换控件；空态/数据不足提示。
- 组件形态由设计系统与前端重构决定，本文档只约束**统计语义与图表数据结构**。

## 4. 实现

### 4.1 数据来源

- 复用 [校园卡](campus-card.md) 去重合并后的本地交易明细缓存（`CampusCardTransactionRecord`）。
- **纯本地计算**，不触发额外联网；明细的获取/同步仍由校园卡功能负责。

### 4.2 计算

```
缓存交易明细（去重合并）
   └─ 按时间窗过滤
        └─ 按时间桶（日/周/月）聚合消费金额
             └─ TrendSeries { buckets: [ { bucketStart, totalAmount, count } ] }
```

- 仅统计消费（支出）类记录；时间桶粒度随时间窗自动选择（短窗按日、长窗按周/月）。
- 金额聚合避免浮点误差（按分计算或定点）。

## 5. 关联

- 依赖：[校园卡](campus-card.md)（交易明细缓存为唯一数据源）。
- 被依赖：[主页仪表盘](../platform/shell/home-dashboard.md)（可作为统计卡片来源，按 #187 显隐）。

## 6. 约束

- 只读分析，不写、不联网（数据来自本地缓存）。
- 统计结果不含敏感信息；数据全本地。
- 无明细或明细不足时降级为空态，不报错。
