# 业务域划分与依赖

> 描述 8 个业务域的边界、共享基座与跨模块依赖关系。

## 1. 全局基座（所有功能共享）

- **数据全本地**：统一存放于各平台**系统默认应用数据目录**（由 `path_provider` 提供，如 Windows `%APPDATA%`、macOS 沙盒容器、Linux `$XDG_DATA_HOME`、移动端应用数据目录）；不再使用 `~/.sspu-aio`；不上云。
- **只读查询**：仅查询展示，不做选课、缴费、充值等写操作。
- **凭据安全**：教务等账号凭据进系统安全存储（`flutter_secure_storage`），不落 `app_state.json`。
- **统一设计系统**：UI 经 `design/qingyuan/qingyuan_ui.dart` 门面，禁裸值（详见 [`DESIGN.md`](../../../DESIGN.md)）。

这些基座由 **平台基础** 模块承载，被其余所有模块依赖。

## 2. 业务域边界

| 业务域 | 边界 | 数据来源 |
| --- | --- | --- |
| 平台基础 | 跨功能的壳层与系统能力 | 本地 / 系统 API |
| 教务 | EAMS 教务系统衍生的所有查询 | 教务网关（需登录） |
| 校园生活 | 校园卡与基于明细的消费统计 | 校园卡网关（需登录）/ 本地缓存 |
| 资讯 | 校内外信息聚合与阅读 | 公开网页 / 公众号源 |
| 邮箱 | 校园邮箱收发 | 邮件协议（需登录） |
| 常用操作 | 快捷跳转与文档查询 | 内置配置 / 公开资源 |
| 校园网 | 网络状态（门禁）、诊断与接入 | 本地网络探测 / 本地 VPN 插件（仅桌面） |
| AI 助手 | 跨域智能问答/汇总/查询/引导；对外 MCP 暴露（只读，仅桌面） | 用户自带模型（BYOK）+ 经授权各域只读数据 |

## 3. 跨模块依赖

- **教务 / 校园生活 → 平台基础**：依赖登录凭据、安全存储、自动刷新、通知。
- **教务内部**：成绩 / 考试 / 日历 / 开课 / 空闲教室 / 培养计划 / 体育打卡 / 第二课堂均依赖「登录与凭据」与教务网关；日历整合课表与考试时间，并与「主页仪表盘」「通知与提醒」联动（课程/考试提醒，#188）。
- **资讯 → 通知与提醒**：新消息触发消息中心与推送。
- **教务 / 校园卡 / 邮箱 → 校园网（门禁）**：受限服务请求前调用 `ensureReachable()` 前置检查，必要时按策略自动连 VPN（#169，仅桌面）。
- **校园网 / VPN → 本地插件机制**：桌面 VPN 由用户手动置入本地 `plugins/` 的插件提供，宿主以独立进程调用（不下载/不分发/不内嵌，许可证进程隔离）；应用内零提及插件/来源；Android/iOS 不提供 VPN。
- **AI 助手 → 各域**：经按域授权的**只读工具**读取各域数据用于问答/汇总/查询；模型为用户自带（BYOK，OpenAI 兼容），数据默认不出域、按需最小必要出域；写操作仅引导不代执行。

## 4. 依赖原则

- 业务域之间**不互相直接引用页面**，通过服务/模型与共享基座解耦。
- 新增跨域联动时在两侧细文档的「关联」一节双向登记。
