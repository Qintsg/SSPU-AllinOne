## 1. 需求

建立国际化基础设施（#192）：抽取硬编码文案为本地化资源，支持语言切换，默认简体中文。

**验收要点**
- 基于 Flutter 本地化（`flutter_localizations` + `intl`/ARB）搭建框架。
- 默认 **简体中文（zh-Hans）**，首批补 **英文（en）** 作为第二语言。
- 语言可在设置切换并持久化；跟随系统为默认。

## 2. 实现（设计中）

- 引入本地化委托与 ARB 资源；将产品文案抽取为键。
- 语言选择（跟随系统/zh-Hans/en）在 [设置中心](../shell/settings.md)「语言」分区，偏好落 [本地存储](../system/storage-sync.md)。
- 与既有「默认简体中文」约定一致；外部 API 文案/数据按来源语言。

## 3. 关联

- 依赖：[设置中心](../shell/settings.md)、[本地存储](../system/storage-sync.md)。
- 被依赖：全应用文案。

## 4. 约束

- 默认简体中文；本地化不改变只读数据来源语言（如教务需 zh_CN，见 [EAMS 基座](../../academic/eams/foundation.md)）。
- 资源键集中管理，避免散落硬编码。
