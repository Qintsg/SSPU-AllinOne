## 1. 需求

提供基于用户自带模型（BYOK）的对话助手，围绕校园各域**只读**数据提供问答、汇总、自然语言查询与操作引导。

**验收要点**
- 对话式交互；模型由用户自配（见 [模型与数据边界](model-data-boundary.md)）。
- 四类能力可用；数据**默认不出域**，按需授权最小必要。
- 写操作（选课/发邮件等）**仅引导**到对应功能，不代执行。

## 2. 能力（四类）

| 能力 | 说明 | 执行边界 |
| --- | --- | --- |
| 跨域问答 | 基于各域只读数据回答问题 | 经授权工具调用取数 |
| 数据汇总/摘要 | 成绩/课表/消息等汇总摘要 | 同上 |
| 自然语言查询 | 自然语言 → 各域只读查询 | **可代执行只读查询** |
| 操作引导 | 指引用户到对应功能 | 写操作**仅引导、不代执行** |

## 3. 交互与界面（期望行为，前端重构后落地）

- 对话界面：复用设计系统 `ai-message` 组件；展示工具调用与数据来源（透明可审计）。
- 对话历史**本地存储、可清除**；敏感内容遵循数据边界约束。
- 数据出域前的授权提示（见 [模型与数据边界](model-data-boundary.md)）。

## 4. 实现

```
用户提问 → 对话编排 → BYOK Provider（OpenAI 兼容）
                        │  工具调用（function calling）
                        ▼
              各域只读工具（经授权 + 最小必要）
                grade / calendar / exam / message / campus-card ...
                        │
              只读查询结果回填 → 模型生成回答
```

- **取数 = 工具调用按需最小拉取**：模型请求某域数据 → 应用校验授权 → 返回最小必要数据再随请求出域。
- 写操作工具**不注册**；操作引导仅返回功能入口/路由建议。

## 5. 关联

- 依赖：[模型与数据边界](model-data-boundary.md)（Provider 配置、工具授权、数据出域策略）。
- 读取（经授权只读工具）：[成绩](../academic/eams/grade.md)、[日历](../academic/eams/calendar.md)、[考试](../academic/eams/exam-schedule.md)、[消息中心](../info/message-center.md)、[校园卡](../campus-life/campus-card.md) 等。
- 引导：各功能页面（写操作不代执行）。

## 6. 约束

- **数据默认不出域**；出域仅在用户开启 AI 且经授权的工具调用时发生。
- 写操作严格不代执行；只读查询经授权可代执行。
- 对话历史本地存储、可清除；敏感数据不进日志。
