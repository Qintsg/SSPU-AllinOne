# 首页密度与行动坞 v04 自评审

## 评审范围

- 页面：`home.dashboard`
- 状态：`initial`、`loading`、`content`、`stale`、`error`、`partial-error`、`credentials-partial`、`operation-locked`
- 主题：亮色、暗色
- 尺寸：360×800、768×900、1200×900、1600×1000
- 证据：`build/design-review-home-density-v04`

## 设计命题

- 使用者：需要在上课前快速确认下一项课程、待办和校园服务状态的在校学生。
- 单一任务：不滚动即可读清“下一件事”，随后用最短路径进入对应校园服务。
- 视觉签名：保留墨蓝“今日学程时间轨”和轨道圆弧，把它作为唯一高强调结构；其余区域使用连续账本和轻量行动坞，不堆叠通用仪表盘卡片。
- 排版与色彩：继续使用 MiSans、清源语义 token 和既有业务域色，不引入新的裸色值、字体或装饰性渐变。

## 自评审过程

第一轮稿否决了“仅缩短卡片”的方案。虽然卡片内部空白减少，但首页根网格仍把四个自动高度区域均分撑满视口，导致标题、状态、主区与行动坞之间出现新的大间距。

第二轮将主区限制为视口高度约 42%、372–420dp，并令所有区域按内容从顶部连续排布。随后检查初始、加载和错误态时又发现状态卡存在外层与内部双重 24dp 内边距，因此在冻结前删除重复内边距。360px 行动坞的左右比例也从 1:1.45 调整为 1.5:1.45，保证“第二课堂”单行显示且三个快捷入口仍各自保持 48dp 命中区。

## 通过判断

- 360×800：内容态无需滚动；标题、状态、时间轨、2×2 概览和行动坞均未被底部导航遮挡。
- 768×900：时间轨与概览保持双栏，但不再为了填满视口而拉高；行动坞紧随主区，空白留在页面背景而非卡片内部。
- 1200×900、1600×1000：时间轨封顶 420dp、单行封顶 60dp，概览行不随窗口无限增长；宽屏不存在巨型按钮或巨型卡片间距。
- 行动坞：第二课堂与常用入口共用单层外框和一个结构分隔；快捷入口取消常驻独立描边，仅在 hover、焦点和按压时给出青雾反馈。
- 状态完整性：陈旧缓存、部分来源失败、部分凭据缺失和刷新锁定保留有效内容；初始、加载和终端错误使用紧凑任务卡并提供唯一明确的下一步。
- 协同性：刷新锁定状态继续展示旧内容并拒绝重复请求；快捷入口的可见标签、外链标识与语义标签使用同一任务名称。
- 动效：快捷入口反馈使用 120ms token；页面进入与刷新旋转沿用既有契约，减少动态时过渡和旋转归零。
- 可访问性：64 张参考稿通过横向溢出、48px 目标、键盘焦点、减少动态、亮暗主题和浏览器控制台门禁。

## 冻结决定

- 冻结版本：`home-density-v04`
- 冻结基线：`build/design-review-home-density-v04`
- Flutter 实现必须保持八种状态、现有服务和存储语义，不新增第二套首页业务状态。
- Flutter 需要把快捷入口实现为透明视觉、48dp 语义目标，并为键盘焦点、hover、按压和减少动态提供一致反馈。
- 若实现阶段暴露新的来源组合、无收藏入口或超大文字状态，必须先补本设计与评审记录，再扩展 Flutter。
