# 响应式导航壳 v01

## 变更性质

本批修正 `shell.navigation` 设计参考路由。高保真清源导航壳已经存在，但此前未接入专用表面映射，导致全量参考误用通用卡片模板。Flutter 导航结构与行为不变。

## 设计任务

- 360×800：主页、教务、课表、信息和更多固定在底栏；邮箱、跳转和设置从更多抽屉进入。
- 768×900：七个目的地全部进入紧凑导航轨，正文获得完整高度。
- 1200×900 与 1600×1000：导航轨显示图标与文字，不改变目的地名称、顺序和当前选中项。
- 三种形态共享同一目的地模型和焦点顺序，只改变空间表达。

## 自评审

- [x] 四档视口和亮暗主题均显示真实清源应用壳，不再出现通用展示卡片。
- [x] 360 底栏不横向滚动，五个目标等宽且均不小于 48dp。
- [x] 768 紧凑轨不挤压应用栏和内容区域。
- [x] 1200/1600 扩展轨标签完整，没有为了填充宽度放大导航项或增加空卡。
- [x] 主目的地名称、顺序、选中态和“更多”归并规则与 Flutter 一致。
- [x] 中央文案只承担导航壳契约说明，不是产品首页，不引入可误触的装饰按钮。
- [x] 导航切换、键盘焦点、更多抽屉关闭与焦点归还继续由现有行为测试覆盖。

## 冻结与验收

- 冻结参考：`build/design-review-shell-navigation-v01`，8 张。
- Windows 候选：`build/visual/windows-shell-navigation-v01`，8 张。
- 对比报告：`build/visual-results/windows-shell-navigation-v01/report.json`。
- 结果：8/8 通过，最低 SSIM `0.920307935050526`。

Flutter 无需修改；只有先产生新设计版本并重新评审，才允许改变目的地、顺序、断点或导航形态。
