# 课程表紧凑端日期带评审 v01

日期：2026-08-19  
分支：`feature/design-language-spec`  
状态：已实现并完成 Windows 本机核验

## 评审对象

评审 [课程表紧凑端日期带 v01](../patterns/course-schedule-day-rail-v01.md)。本批只处理有可用课程数据时 360/390px 的日期选择带，不改变 768px 以上的完整周视图或任何请求状态。

## 证据与结论

- Windows 当前 360×800 亮、暗候选中，周六为当天时自动 reveal 使左端出现截断的日期标签；1200px 周网格和 768px 全称页签无此问题。
- 第一轮 360px 候选虽消除了截断，但单字“⼀”过像短横线；冻结为等宽的两字周名与“今天”，以紧凑字阶保留清晰扫读，且周一至周日仍有独立 48dp 控件。
- 视觉短标签与完整语义标签分离，读屏和键盘用户仍获得“周六，今天”及互斥选中状态。
- 设计没有增加卡片、按钮外框、数据请求或设置项；页面空白仍属于内容背景，而非人为拉高的卡片。

## 实施验收条件

1. 360/390px 不得出现截断日期文字、横向页签滚动或小于 48dp 的日期目标。
2. 点击和左右箭头可以从周一移动到周日；当前日期初始选择、刷新锁定与显示课程不变。
3. 768px、1200px、1600px 保持原有全称标签和桌面周网格，不发生布局倒退。
4. 完成 `course_schedule_page_test.dart`、清源组件相关测试、静态分析、设计门禁与四档亮暗视觉候选复核；本批不计算 SSIM。

## 实现与核验

- `YhTab` 现可将视觉标签与语义标签分离，`YhTabs.distributeEvenly` 为固定数量的紧凑任务提供完整等宽日期带；普通页签仍采用原有可滚动实现。
- `CourseSchedulePage` 仅在 medium 断点以下使用七个 48dp 日期目标，呈现“周一…周五、今天、周日”；点击、左右方向键、刷新锁定、缓存/失败恢复和 768px 以上的完整周网格保持原有逻辑。
- 初版截图发现单字“⼀”易误读为短横线后，先回写模式稿并复审为两字周名与“今天”，再重新实现与采集；没有用候选图反向修改基线。
- 新增 360×800 固定物理视口回归，覆盖全部日期文字、完整语义、无横向滚动、每项至少 48dp，以及点击周日后的状态更新。
- `course_schedule_page.dart` 拆为 476 行的页面控制器、212 行状态面板与 402 行响应式视图，接口和行为不变。
- `course_schedule_page_test.dart` 与 `qingyuan_component_catalog_test.dart` 共 34 项通过，`flutter analyze --no-fatal-infos` 与 `git diff --check` 通过。Windows 本机重新采集课程表 7 态 × 4 视口 × 亮暗主题，共 56/56 张；人工复核 content/stale/operation-locked 的 360 亮暗和 768/1200 代表图，未计算 SSIM。
