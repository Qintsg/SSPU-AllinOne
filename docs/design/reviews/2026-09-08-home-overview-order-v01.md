# 首页服务摘要排序 v01 自评审

## 评审结论

设计命题是“可配置但不打散首页时间语境”。首版把显隐开关与排序列表重复展示，造成四项服务文案出现两次，已否决。冻结稿改为两段单层账本：固定区域每项只显示开关，可排序摘要每项只出现一次并合并上移、下移和显示开关。

## 自评审检查

- 360×800：操作组在摘要标题下右对齐，页面自然滚动，底部导航不遮挡当前行。
- 768×900 / 1200×900 / 1600×1000：标题、位次和操作同行，四行保持连续阅读，不增加嵌套8卡。
- 亮暗主题：只使用清源语义 token；禁用箭头与可用箭头有明确对比。
- 输入：触控、鼠标与键盘共用显式按钮；首末边界禁用；开关仍即时写入。
- 语义：每个箭头包含动作与服务名；“第 N 位”只表达真实顺序。
- 动效：排序变化使用既有页面重建；系统减少动态时绕过 `AnimatedSize`。

## 参考与差异

参考 [UCSD campus-mobile 卡片配置](https://github.com/UCSD/campus-mobile/blob/master/lib/ui/profile/cards.dart) 的无障碍排序路径。该项目对普通输入采用拖拽、对可访问导航采用上下按钮；清源面向五端与键盘场景，选择始终显示上下按钮，降低隐藏交互和跨平台拖拽差异。
