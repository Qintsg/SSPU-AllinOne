# 首页密度与行动坞 v05 冻结修正评审

## 修正原因

v04 自评审决定 360px 行动坞采用 1.5:1.45 的近等宽比例，使“第二课堂”单行显示并为三个 48dp 快捷操作保留空间；但专属样式拆分后，基础选择器 `.section-card.home-utility-dock` 的优先级高于 360px 媒体规则 `.home-utility-dock`，冻结截图实际仍采用 2:3。该截图与已记录的设计决定冲突。

## 修正范围

- 只把 360px 媒体规则提升为同等选择器优先级，不读取或复制 Flutter 候选图。
- 页面、八种状态、主题、断点、文字、业务数据、颜色、动效和交互语义均不变化。
- 768×900 继续使用 1:2 的“摘要—行动”比例；1200×900 与 1600×1000 继续使用 2:3。

## 自评审结论

- 360×800 的“第二课堂”恢复单行，三个快捷入口各自保持 48dp 目标，行动坞没有横向溢出。
- 单层外框、内部结构分隔和无常驻按钮描边保持不变。
- 八态、四档尺寸、亮暗主题共 64 张重新通过浏览器溢出、键盘、目标尺寸、减少动态和控制台门禁。
- 修正后的冻结基线为 `build/design-review-home-density-v05`；v04 仅保留为缺陷追溯证据，不再作为 Flutter 比较基线。

## 实现复核

- Flutter 证据：`build/visual/windows-home-density-v08`
- 差异报告：`build/visual-results/home-density-v08/report.json`
- 视觉结果：64/64 逐图达到 SSIM 0.90，最低为暗色 360×800 初始态的 `0.916481237559729`。
- 响应式：360×800 默认文字比例无需滚动；768 使用 1:2 行动坞，1200/1600 使用 2:3；主区在宽屏封顶 420dp，行动坞在中等宽度收至 80dp。
- 操作协同：刷新锁定保留当前内容并拒绝重复请求；三个快捷入口使用无常驻描边的 `YhPressable`，支持点击、Enter/Space、hover、焦点、按压、48dp 目标和减少动态。
- 结构：原 1496 行首页视图拆为 455、592、466 行三个职责文件；新增独立密度测试，未建立第二套业务状态。
- 工程回归：`flutter analyze` 零问题，设计系统 36 项门禁通过，全量 `flutter test` 673 项通过，Windows Release 构建通过。
- 平台边界：本记录只证明 Windows；Android、iOS、macOS、Linux 仍由对应 CI runner 采集、比较和构建，不能据此表述为五平台全部完成。
