# 安全与账户全量参考修正 v03

## 变更性质

本批不调整按钮、卡片、设置项或 Flutter 页面。它只修正全量设计参考采集时将“常规”设置误写为 `settings.account` 的路由冲突，并重新冻结既有“安全”分区设计。

## 页面任务与设计意图

- 页面唯一任务是让学生连续完成应用保护、系统快速验证、校园服务凭据维护，以及进入数据与隐私管理。
- 视觉特征保持为“本地保护在前、凭据维护在后”的连续任务面；安全开关、动作和凭据表单属于同一上下文，不拆成空洞的小卡片。
- 错误提示在凭据区域原位出现，保留开关、输入框、已有文本与数据管理入口，避免失败状态中断其他可执行任务。

## 自评审

- [x] 16 张图片均显示“安全”分区，而非“常规/首页显示”分区。
- [x] `content` 与 `error` 在亮暗主题、360×800、768×900、1200×900、1600×1000 下均完成目视检查。
- [x] 360 使用顶部分区选择器和底部主导航；内容可滚动但不存在页面级横向溢出。
- [x] 768 使用紧凑主侧栏；1200 与 1600 展开设置分区导航，宽屏内容列保持封顶。
- [x] 错误横幅保留安全开关、凭据表单与重试动作；重试后原位恢复，不清空任务上下文。
- [x] 所有交互目标通过 48dp 门禁，键盘焦点、Escape 关闭和焦点归还通过浏览器自动核验。
- [x] 页面没有新增装饰性卡片、重复按钮或为了填充宽屏而放大的空白区域。
- [x] 视觉方案仍来自清源的校园服务任务语义，没有引入通用仪表盘式装饰。
