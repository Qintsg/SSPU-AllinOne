# 首页与通知密度 v17

## 设计目标

- 页面任务：让用户在同一张“首页显示”账本中快速决定首页出现哪些内容，不把每个开关拆成独立大卡。
- 视觉特征：以“时间与学习 / 校园服务”两段真实语义分组组织八个开关；强调设置的协同性，而非装饰性统计。
- 本轮只调整视觉契约，不新增或删除设置项，也不改变开关即时生效行为。

## 自评审

- [x] 360×800、768×900、1200×900、1600×1000 与亮暗主题共 8 张参考图全部通过浏览器交互、控制台、语义和 48dp 目标检查。
- [x] 行标题显式使用 `--weight-h1`（600），不再依赖浏览器 `<b>` 的默认粗体，HTML 与 Flutter 共用同一 token 语义。
- [x] 360 的卡片底部 padding 从 32dp 收到 16dp；最后一项仍有清晰呼吸，卡片不再被底部导航遮挡，也不保留无任务空带。
- [x] 八个开关的可见轨道保持 44×26，命中目标不小于 48dp；压缩的是空白而不是操作目标。
- [x] 图标继续按日历、信息、培养、校园卡、邮件和链接语义区分，不能用与业务无关的通用网格或人物图标替代。
- [x] 768 采用导航轨与自然滚动，1200/1600 使用分区导航；宽屏没有为了填满窗口而拉高卡片。
- [x] 动画继续使用清源 200ms 开关过渡，并尊重减少动态设置。
