# 清源组件工作台参考稿 v03 评审记录

日期：2026-08-17  
分支：`feature/design-language-spec`  
状态：冻结，允许进入 Flutter 实现

## 设计对象

本批覆盖六张给维护者和设计评审者使用的清源组件工作台页面：操作、输入、反馈、导航、数据和校园域。它们不是生产应用导航壳，不显示应用底栏或导航轨；每页只展示同一组件契约下的三组真实状态。

工作台采用 56dp 契约栏、最大 1152px 内容宽度和按内容收口的契约卡：

- 360px：单列，16dp 页面内边距，三张卡连续滚动可达。
- 768px：双列，宽输入/导航卡跨两列，其他卡保持内容高度。
- 1200px 及以上：三列，宽卡只在确实需要组合内容时跨两列。
- 所有按钮、开关、分页、导航目的地和撤销行动的可见命中区域不小于 48×48dp。
- 输入标签持续可见；错误文本贴近对应字段；空状态和确认行动保留下一步方向。

## 自评审结论

v01 未冻结：旧状态参考样式会隐藏窄屏第二、第三张卡，且工作台类名与旧原型冲突，导致输入框被拉高、行动按钮被迫纵向堆叠。

v02 解决了布局冲突并通过视觉浏览，但交互控件仍是静态示意。v03 补齐了操作协同：

- 分段选择和页内 Tab 支持点击与方向键，选中态、ARIA 状态和焦点同步。
- 开关、复选、单选、分页和底栏/导航轨目的地同步状态。
- 连续滑块支持方向键，以 4% 增量更新值和轨道。
- Toast 撤销行动更新反馈文案并进入已撤销状态。
- 减少动态时不保留工作台动画；最后一张契约卡可以滚动到达。

## Flutter 实现约束

实现只复用现有业务服务、模型和状态契约；组件工作台视图拆到独立文件，按本稿的单列/双列/三列规则组织。不得把生产应用壳、旧 Fluent 成品控件或裸设计值带入工作台。实现后必须运行组件视觉矩阵、布局/语义/键盘测试，并以每张截图 SSIM ≥ 0.90 独立验收。
