# 清源组件工作台参考稿 v04 评审记录

日期：2026-08-17  
分支：`feature/design-language-spec`  
状态：冻结，取代 v03 作为组件工作台验收基线

## 修订原因

v03 已解决组件工作台的响应式结构和交互协同，但实现预检显示少数参考图仍在描绘旧的静态示意，而不是清源组件的真实语义。v04 只调整组件内部表达，不改变三张契约卡、单/双/三列断点、页面密度或导航层级。

## 已评审的设计变更

- 搜索和日期控件保留持续标签，同时补充输入类型图标与日期前后提示。
- OTP 使用一个可粘贴、可被辅助技术完整读取的定长输入，不拆成六个独立焦点格。
- 空状态增加紧凑图标，但降低图标、标题和内边距，避免形成大面积空卡。
- 折叠说明改为真实披露控件，标题和内容在同一边界内表达展开关系。
- FAB 使用胶囊轮廓；被选中的 Chip、分页和主目的地使用清源浅色/实色选中语法。
- 课程块改为低饱和校园域底色；指标数字使用中等字重，避免数值卡过度抢占层级。
- 快捷入口保持整行 48dp 目标，并同时呈现名称与用途说明。

这些调整优先保证操作协同、粘贴/键盘便利、可读性和紧凑密度，没有新增生产应用导航或无意义装饰。

## 浏览器核验

```powershell
uv run --with playwright python scripts/design/verify_design_prototype.py `
  --output build/design-review-components-workbench-v04 `
  --surface-prefix components.
```

结果：48/48 张参考截图生成并通过门禁，覆盖六页、亮暗主题及 360×800、768×900、1200×900、1600×1000。

复审确认：

- 360px 无横向溢出，三张卡连续滚动可达。
- 768px 双列和 1200px 以上三列保持稳定；宽卡只在输入和页内导航中跨列。
- 卡片均按内容收口，没有被网格拉高或用空白填满视口。
- 搜索、日期、OTP、折叠、撤销、分页和目的地状态有明确语义与 48dp 命中区域。
- 暗色对比、键盘焦点、方向键协同和减少动态门禁全部通过。

冻结截图目录：`build/design-review-components-workbench-v04`。Flutter 必须以该目录逐图执行 SSIM ≥ 0.90 验收；后续若再改变组件信息或交互，需新增版本而不是覆盖本目录。
