- 快捷入口目录已对齐紧凑排版、任务行间距、外链角标与环形加载态；Windows candidate 四档视口与亮暗主题 32 张逐图均达到 0.95。
- 首页已对齐全状态紧凑排版、时间轨装饰圆、概览图标、陈旧缓存横幅与辅助坞等高布局；Windows candidate 四档视口与亮暗主题 40 张逐图均达到 0.95。
- 邮箱收件箱已对齐紧凑状态卡、环形加载、透明 neutral 状态、缓存横幅与移动邮件行；Windows candidate 六态、四档视口和亮暗主题 48 张逐图均达到 0.95。
- 邮箱撰写已对齐紧凑页首、地址字段断点、多行文本度量与发送中可读禁用态；Windows candidate 四态、四档视口和亮暗主题 32 张逐图均达到 0.95，最低 0.952726。
- 邮件正文详情已通过共享 reading 排版 token 对齐长文行高、段落节奏与弱化前景；Windows candidate 四档视口和亮暗主题 8 张逐图均达到 0.95，最低 0.954896。
- 校园资讯流已对齐六态固定高度面板、环形加载、紧凑来源药丸、两行标题与摘要节奏；Windows candidate 六态、四档视口和亮暗主题 48 张逐图均达到 0.95，最低 0.962316。
- 资讯来源筛选与空结果面板已改用无交互污染的确定性状态，保留空搜索框、默认来源和固定高度品牌空态；Windows candidate 两态、四档视口和亮暗主题 16 张逐图均达到 0.95，最低 0.961757。
- 外部网页确认页在内容与认证阻断两态下保持目标域名、返回路径和前置条件可见；Windows candidate 四档视口和亮暗主题 16 张逐图均达到 0.95，最低 0.971046。
- 法律声明、隐私说明和用户协议已迁移到结构化清源阅读框架，保留随包完整正文的可选择阅读、加载失败重试和主要行动；Windows candidate 三页、四档视口和亮暗主题 24 张逐图均达到 0.95，最低 0.954979。
- 外观设置已迁移到共享清源任务页框架，保留即时主题切换、来源说明和设置内真实入口；Windows candidate 四档视口和亮暗主题 8 张逐图均达到 0.95，最低 0.963115。
- 分段控制器落实 roving focus 与左右方向键切换；外观摘要只展示当前主题，避免与独立任务页形成重复编辑路径。
- 上述结果只证明 Windows candidate 对齐；正式完成仍以参考确认冻结及 Android、iOS、Windows、macOS、Linux 五平台矩阵通过为准。
- 新增独立于 Flutter 实现的 44 界面参考目录，补齐视觉清单全部 123 个页面/状态组合。
- 浏览器核验现在固定生成四档视口、亮暗主题共 984 张设计参考候选，并写入逐图 SHA-256 索引。
- 五平台 Flutter 候选上传前必须通过文件名、PNG 尺寸和外部区域 sidecar 边界校验。
- 外部区域改为逐状态声明；PDF/WebView 加载与错误、系统认证说明等清源自绘内容不再错误使用 0.95 阈值。
- 次级参考稿按时间轨、课表、记录、邮箱、表单、设置、法律、文档和系统认证等页面结构分别渲染，不再复用单一卡片模板。

## 0.3.1 - 2026-07-19

- 新增 `opacity.domainTint` 机器 token，统一业务域图标浅底的 CSS 与 Flutter 混色比例。
- 快捷入口新增外部网页确认页，固定目标域名、离开应用提示和 OA 登录会话缺失阻断状态。
- OA 外部入口门禁以可复用登录会话为准，不再把“已保存凭据”误判为当前登录态。
- 快捷入口错误态明确显示内置配置位置，并同步独立收藏、外部语义与认证门禁组件规格。
- 将布局尺寸 token 同步到 HTML 样例的 CSS 语义变量，并纳入漂移门禁。
- NavRail 在 medium 使用 80px compact 形态，在 expanded 起使用 220px extended 形态。
- 页面参考稿严格按 360×800、768×900、1200×900 和 1600×1000 视口输出，不再使用全页高度。
- 应用壳显式清除组件样例页的 `body` 外边距，确保导航与背景铺满视口。
- 课表 content 参考稿补全周一至周日，对齐固定脱敏数据和 09:30 时钟，compact 始终露出当天 Tab。
- 浏览器交互验证后强制重载原型，防止 Tab、筛选、邮件选中或设置分区污染默认 content 参考稿。
- HTML 参考稿显式加载 MiSans 四档字重，并校验排版字体 token，避免浏览器回退字体造成伪差异。
- 课表周视图在 medium 以上压缩为完整七列，CourseBlock 统一为业务域 tint，当前日整列使用青雾强调。
- 页面内容宽度、流式边距、状态药丸、NavRail、Tabs 与 IconButton 的 Flutter 契约同步到参考原型。
- 邮箱参考稿补齐收件箱 initial/loading/empty/stale/error、独立只读详情 content 与撰写 initial/content/loading/error，四档视口和亮暗主题均可确定性采集。
- 快捷入口参考稿补齐 loading/content/empty/error，保留任务分组、搜索无结果和明确恢复动作。
- 快捷入口目录补齐六个独立 48px 收藏按钮、按压语义与收藏反馈，避免迁移时丢失既有收藏能力。
- 快捷入口参考稿按配置语义固定教务、馆藏、校园卡、官网与认证图标，并使用对应业务域色。
- 参考稿采集前统一将鼠标移出内容区，防止 reload 后残留指针位置污染默认态截图。
