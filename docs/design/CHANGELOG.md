# 清源设计系统变更记录

## 0.3.1 - 2026-07-19

- 将布局尺寸 token 同步到 HTML 样例的 CSS 语义变量，并纳入漂移门禁。
- NavRail 在 medium 使用 80px compact 形态，在 expanded 起使用 220px extended 形态。
- 页面参考稿严格按 360×800、768×900、1200×900 和 1600×1000 视口输出，不再使用全页高度。
- 应用壳显式清除组件样例页的 `body` 外边距，确保导航与背景铺满视口。

## 0.3.0 - 2026-07-18

- 指定 `resources/tokens.json` 为唯一机器真源。
- 统一低饱和校园业务域色、36/28/22/18 字阶与 120/200/320ms 动效。
- 增加断点、控件尺寸、焦点环、输入框与磁贴圆角契约。
- 明确 Android、iOS、Windows、macOS、Linux 五个发布平台共享语义契约，但允许布局密度、导航形态和输入反馈适配；Flutter Web 不在本轮验收范围。
- 增加逐图 SSIM 验收工具：应用区域阈值 0.99，系统认证、网页和 PDF 等外部区域阈值 0.95，并在失败时输出实际图、基准图、差异热图和 JSON 报告。
- 明确清源组件与迁移期 Fluent 宿主的边界。
- 确立“今日学程时间轨”为首个纵向切片的视觉签名。
- 完成七个主目的地、详情边界与关键状态的页面级契约及响应式交互原型。
- 优化 compact / medium 设置分区、组内方向键导航、搜索空状态和页面行动反馈。

## 0.2.0 - 2026-06-16

- 建立清源总纲、基础令牌、44 份组件规格和对应 HTML 样例。
