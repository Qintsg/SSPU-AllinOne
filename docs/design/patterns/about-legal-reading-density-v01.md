# 关于与法律阅读密度 v01

## 目标

本稿服务于需要确认应用版本、许可或隐私边界的学生。页面的单一任务分别是“辨认构建信息并进入正确入口”与“连续、可选择地阅读法律正文”。短账本或短预览不能为了填满视口而被描成大面积边框卡；真实长文仍需获得稳定、可滚动的阅读区域。

## 视觉方向

- 沿用清源的结构蓝来源标记、松石主要动作、MiSans 与现有圆角/边框 token；不新增颜色、图标、插画或拟物装饰。
- 本批的签名是“有边界的阅读列”：信息边界只包围实际内容，宽屏贴齐标题左缘，余白回归页面背景，不伪装成一张未完成的卡片。
- 关于页的三行构建账本是操作清单，不是仪表盘：每行保留状态和一个 48dp 操作，账本宽度收束到 `layout.formContentWidth`，高度随三行内容自然结束。
- 法律页的正文容器宽度只包住既有的可读列及内边距。原有正文最大宽度不缩小；短 fixture 不拉高，真实长文按自然高度由页面滚动承载。

## 响应式编排

```text
360 / 768                              1200 / 1600
┌ 标题、摘要、主要操作 ┐               ┌ 标题、摘要 ──────── 主要操作 ┐
├ 来源条                ┤               ├ 来源条 ──────────────────────┤
├ 构建账本 / 法律阅读列 ┤               ├ 阅读列（左锚定、内容高）┐   │
│ 信息、说明、操作      │               │ 信息、说明、操作         │   │
└──────────────────────┘               └─────────────────────────────┘
```

- 360px：关于账本与法律阅读列占满内容列；主要操作独占一行，行内操作保留 48dp 命中面积。长文以单页面滚动继续，底部导航不遮挡最后一节。
- 768px：短法律预览不增加人工最小高度；关于账本仍以可读宽度收束，避免横向空框。
- 1200px 与 1600px：标题、来源条保持现有页面骨架；账本及法律正文卡左锚定，其右侧留白属于背景。法律正文的文字列维持既有 17 个 48dp 单位的上限，不以“美化”理由压窄正文。
- loading：来源、返回与主要操作保持可用，加载提示自然占高。
- error：错误说明和“重新加载”相邻，不以全高卡片降低恢复可见性。
- 正常动效仅沿用已有 `motion.base`；减少动态时直接完成布局变换。

## 范围与边界

覆盖：`SettingsAboutPage` 的构建账本，以及 `LegalNoticePage` 的页面/章节容器约束。

不覆盖：法律文本、来源说明、路由、更新检查、外链确认、许可清单、数据管理、加载器和 service。既有条目、文案、语义标签、焦点归还及单飞锁均保持不变。

## 自评审

1. **保留填满视口的最小高度**：否决。1600 宽度候选中，三行信息仅占顶部，剩余边框内没有可读内容，造成“还有内容未加载”的错觉。
2. **去除关于/法律的一切表面边界**：否决。会让构建操作和可选择的协议正文失去清晰范围，弱化键鼠定位。
3. **内容高、左锚定的窄阅读表面**：采用。保留账本和正文的语义边界，删除无信息空框；宽屏和窄屏都有稳定的起点与阅读顺序。

## 核验清单

- 视口：360×800、768×900、1200×900、1600×1000；亮暗主题。
- 状态：关于 loading/content/error/external-confirmation/operation-locked；法律 content/loading/error。
- 操作：返回、检查更新、版本详情、许可清单、文档信息、重试、主要法律动作、Tab/Shift+Tab/Escape。
- 可访问性：48dp 操作目标、标题语义、正文可选择、错误 live region、无横向溢出、减少动态。
- 回归：长法律正文不裁切，外链确认和失败恢复不丢失，真实服务和数据契约不改动。

## 实现界限

仅使用既有清源 token 与 `Yh*` 组件。禁止引入裸视觉值、旧 Fluent/Material/Cupertino 成品控件，禁止为通过截图而重录设计基线或改变业务状态含义。
