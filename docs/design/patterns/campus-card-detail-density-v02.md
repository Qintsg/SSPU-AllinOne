## 用户与单一任务

对象是已拥有校园卡本地快照的学生。进入页面后的单一任务是：先确认余额是否可信，再在不误触远端访问的前提下限定日期、查询或同步交易记录。

## 视觉方向

本页采用“**随身账本，而非横幅仪表盘**”的编排。余额是一张紧凑的墨青账本签，不以整行色块占据无信息空间；日期、查询与同步属于同一操作账本，按操作优先级而非按钮外框数量组织。

调色与字形只使用清源 token 的既有角色：纸白 `neutral.surface`（`#FFFFFF`）、正文墨 `neutral.fg`（`#1C1B1A`）、边界灰 `neutral.border`（`#D1CEC9`）、清源青 `brand.strong`（`#478384`）、青雾 `brand.tint`（`#E9F0F0`）、收支红 `service.finance`（`#B85C6A`）。标题、正文与金额均为 MiSans；金额保留现有 mono 角色以提高扫读性。

## 冻结编排

```text
1200+
┌ 余额账本签 320 ┐  ┌────────── 交易查询账本 ──────────┐
│ 校园卡余额      │  │ 交易记录                 近 7 天 │
│ ¥128.50        │  │ [开始日期] [结束日期] 查询记录  │
│ 正常 · 09:30   │  │               ↻ 同步全部记录    │
└────────────────┘  │ 全部 / 支出 / 收入               │
                      └──────────────────────────────────┘
┌ 交易卡 ─┐ ┌ 交易卡 ─┐ ┌ 交易卡 ─┐

360 / 768
┌────────────────────────────────────┐
│ 校园卡余额 / ¥128.50 / 正常 · 09:30 │
├──── 交易记录 ─────────────── 近 7 天 ┤
│ [开始日期                            ]│
│ [结束日期                            ]│
│ [查询记录]       ↻ 同步全部记录       │
│ 全部 / 支出 / 收入                    │
└────────────────────────────────────┘
```

- `expanded`（1200 起）才使用“余额账本签 + 查询账本”两列；中等和紧凑视口保持连续单列，避免在 768 宽度压缩输入框。
- `近 7 天` 是填充日期的本地快捷操作，使用 48dp 无框文本动作；不是会被误认为远端操作的描边按钮。
- `查询记录` 保持唯一主按钮；`同步全部记录` 改为带同步图标的 48dp 文本动作，仍明确是远端只读操作。
- 有效内容、过期、部分失败、操作锁定和日期校验均保留余额、输入、方向、页码和返回上下文；锁定时三个操作与输入共同禁用。
- 没有可恢复内容的终端错误，以及“当前范围无交易”空状态，最大宽度收束至 `layout.formContentWidth`，不把空状态卡横向拉满。

## 动效与可达性

- 输入、按钮与标签沿用清源 `fast`/`base` 动效；减少动态时由基础组件立即切换。
- 主、次远端动作共享现有单飞锁；文本化不降低 48dp 命中面积、焦点可见性或语义名称。
- DOM/Widget 焦点顺序保持：快捷日期、开始日期、结束日期、查询、同步、方向筛选。视觉位置调整不改变动作含义。

## 不在本批范围

不改变服务、缓存、凭据、请求参数、过滤规则、交易排序、分页或任何首页设置。不会新增消费汇总、伪统计、装饰卡或新的远端请求。
