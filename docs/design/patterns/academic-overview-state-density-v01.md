## 场景

当教务总览没有可展示快照时，用户需要理解“当前为什么没有数据”和“接下来能做什么”。初始、加载、空、凭据不足和错误不是仪表盘内容，不能被桌面剩余高度拉成一张宽大空卡。

## 参考编排

```text
360px                              768px 及以上
┌──────────────────────────┐       ┌──────────────────────────────┐
│ [图标] 恢复状态标题        │       │ [图标] 恢复状态标题          │
│ 原因与安全边界说明          │       │ 原因与安全边界说明            │
│ [唯一恢复行动，48dp]       │       │ [唯一恢复行动，48dp]         │
└──────────────────────────┘       └──────────────────────────────┘
查看详细数据源                     查看详细数据源
```

## 冻结规则

- 所有无内容状态面板按内容高度结束；不得使用 `popoverWidth` 或视口高度作为最小高度。
- 宽度不超过 `layout.formContentWidth`，并与页面内容列左缘对齐；360px 时自然占满可用内容宽度。
- 初始、空、凭据不足和错误继续显示图标、完整标题、原因和一个恢复行动。加载/操作锁定保留现有活动指示、实时语义和锁定说明。
- 凭据不足必须明确“当前不会发起校园服务请求”；错误继续引导校园网络或 VPN 检查；空状态继续提供调整学期。不得合并或含糊这些恢复路径。
- 恢复面板与“查看详细数据源”间保持 `spacing.xl`，详细来源仍可被键盘跳转并在协同刷新时不可操作。

## 方案比较与自评审

1. **缩小现有全宽大卡**：否决。即使高度降低，宽卡仍让恢复信息像仪表盘主内容，且在 1200px 留下无意义横向边界。
2. **移除卡片，仅保留横幅**：否决。初始、空和认证缺失需要清晰的主行动及可聚焦分组，横幅会降低操作可发现性。
3. **左锚定的内容高度恢复面板**：采用。它保持状态与唯一行动的关系，又将大屏空白还给页面背景，使详细数据源自然接续。

## 验收边界

本批只调整无内容状态面板的最大宽度和最小高度。数据源请求、缓存、状态选择、动作回调、锁定语义、标题文案、按钮文案与详细来源内容均不变。人工核验覆盖四档亮暗 initial、loading、empty、credentials-required、error 与 operation-locked；重点确认无横向溢出、48dp 行动、锁定反馈和来源区可达。
