## 目标

对象是需要迅速恢复教务来源数据的在校学生；页面的单一职责是在不丢失筛选、返回路径和现有快照的前提下，说明当前状态并提供唯一的下一步。现有共享状态卡已取消固定高度，但仍以居中的“海报”顺序堆叠图标、标题、说明和按钮：360px 考试读取失败时，短信息占用约 323dp 的边框区域，恢复动作与错误原因相距过远。

本稿将其压缩成左锚定的“恢复账本”：状态符号、事实说明与唯一动作像一条可扫读的事务记录，而不是占据页面的宣传块。

## 视觉方向

- 使用既有清源中性色、教务服务蓝、松石交互色、MiSans 和 `YhCard`；不增加颜色、插画、图标包或新的业务文案。
- 状态符号固定为 `control.minimumTarget`，标题与说明在相邻的文本列中左对齐。符号只标注状态，不抢占标题层级。
- 360px 下，第一行容纳状态符号和文本列；唯一动作紧随其后、左对齐。说明较长时自然增加文本行数，不拉高无信息留白。
- 768px 及以上，将操作放入同一行的尾部；宽度仍由 `formContentWidth` 收束，不能因短信息扩至整页。
- `loading` 不显示虚假操作；空和错误状态保留各自既有的明确动作、单飞锁与语义。正常动效只使用 `motion.base`，减少动态时立即切换。

```text
360px                                     768px / 宽屏
┌ [!]  考试安排暂不可用 ┐                ┌ [!]  标题与恢复说明       [重试] ┐
│      校园网或 VPN 后重试│                └──────────────────────────────────┘
│ [检查后重试]            │
└────────────────────────┘
```

## 响应式与稿外状态

- 360×800：状态卡占内容列；操作始终保持 48dp 目标，键盘焦点和底部操作区互不遮挡。
- 768×900：文本列可获得更长行宽，操作与内容同排或在狭窄时自然落至下一行；不裁字、不横向滚动。
- 1200×900 与 1600×1000：卡片左锚定、限制为 `formContentWidth`，正文之后保留的是页面背景而非无意义卡片内白。
- `loading`：活动环、标题和恢复说明同组；无可点击操作，仍可返回。
- `empty` / `error`：分别明确范围无内容或读取原因；重试不修改既有筛选、缓存或请求参数。
- `stale` / `operation-locked`：已有内容、横幅和禁用策略不变；本稿只作用于“无内容”的恢复卡。

## 自评审

1. **只减少内边距**：否决。居中海报结构仍会让图标、说明和动作彼此割裂，且长错误文本会重新形成空白区。
2. **移除 `YhCard` 只保留裸横幅**：否决。空状态与错误状态会失去可扫描的恢复边界，触控与焦点目标也不再显性。
3. **采用紧凑恢复账本**：采用。阅读从状态符号到事实、再到操作连续发生；窄屏在必要处换行，宽屏不再堆叠短信息。

## 实现界限

仅调整 `_AcademicDetailLoadingState` 和 `_AcademicDetailMessageState` 的内部排列及 `_AcademicDetailStateCard` 的内边距策略。保留所有 service、缓存、路由、筛选、测试 fixture、回调、错误文案与现有 token；禁止裸像素值和成品 Fluent/Material/Cupertino 控件。
