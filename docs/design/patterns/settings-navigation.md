# 设置导航与常规分区

## 用户任务

学生需要快速找到首页显示、通知、学期、刷新、账户安全和内容来源设置；低频入口不能遮挡高频开关，也不能因为窗口变窄而截断恢复路径。

## 信息架构

保留生产中的 8 个分区及其既有语义：常规、学期、自动刷新、安全、职能部门、教学单位、微信推文、关于。外观、应用更新和本地数据继续使用独立任务页，但从相邻的语义分区进入。

常规分区按使用频率排列：

1. 首页显示：8 项开关保持独立，先“时间与学习”，后“校园服务”。
2. 消息推送：总开关、勿扰开关和时间范围保持在同一操作上下文。
3. 应用体验：关闭按钮行为、外观和更新入口合并到一张紧凑卡片，不再形成三张大摘要卡。

## 响应式导航

- 360–899：单一“当前分区”触发器打开底部抽屉，支持 Escape、焦点循环、遮罩关闭和焦点归还。
- 900–1199：顶部标签；标签必须完整显示或可感知地滚动，不允许静默截断最后一项。
- 1200 及以上：左侧分区导航，不套外层大卡；内容区封顶，不随窗口无限拉宽。
- 设置内容允许纵向滚动；开关始终与对应标题同行，简单开关不得因为紧凑宽度被堆到下一行。

## 画面密度

- 每张卡只表达一个操作上下文，卡内使用分组标题和分隔线，不为每个设置项重复套卡。
- 应用壳已有“设置”标题时不再重复大标题和说明；内容直接从分区导航开始。
- 分区触发器自身就是唯一表面，不再叠加外卡；卡标题下不重复解释已经由设置项名称表达的内容。
- 设置行采用 56dp 紧凑节奏，并用轻量业务图标锚点提高扫读速度。
- 卡内使用图标与留白分组，不叠加贯穿整行的分隔线；宽屏导航保留“系统设置 / 消息推送设置”上下文标签。
- 开关保持 48dp 命中区，视觉轨道只占实际尺寸。
- 低频按钮使用无边框文字层级；进入专用任务页后再展示完整主操作。
- 360 与 768 的首屏优先展示 4–6 个首页开关；1200 与 1600 不通过放大行高填满画布。

## 动效与协同

- 分区切换只使用短时淡入和最多 2% 的位移；减少动态时位移和时长归零。
- 抽屉从触发器所在层级出现，关闭后归还焦点。
- 设置写入失败保留当前值并在原位置说明；服务、账户或页面代次变化后，旧请求不得覆盖新值。
