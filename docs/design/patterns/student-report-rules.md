# 第二课堂积分规则页

## 页面任务

学生进入本页时首先需要确认“还差多少分”，然后找到可补齐的类别和具体计分条件。页面保留源站返回的完整规则，但不复刻网页矩阵，也不在字段缺失时推测最终学分。

## 设计方向

- 主题：第二课堂成长账本，面向需要核验毕业要求和补齐学分的在校学生。
- 单一任务：判断完成差额，并定位下一项可执行的积分条件。
- 视觉签名：一条连续的“完成差额刻度”贯穿总览和类别明细；它表达真实的 `已获 / 必修` 关系，不作为装饰。
- 调色板：纸面 `#F7F6F4`、表面 `#FFFFFF`、正文 `#111418`、弱文字 `#6F716F`、第二课堂 `#6A8C5C`、通过 `#1F8F57`；暗色全部使用 `tokens.json` 对应值。
- 字体：沿用清源唯一字体真源 MiSans；标题使用显示字阶，正文使用正文字阶，积分和差额使用等宽数字特性。为保持五平台确定性，本批不引入额外字体。

## 响应式与交互契约

- `< 768dp`：总览和所有类别形成连续账本；不使用横向滚动，不重复套卡，字段自然换行。
- `≥ 768dp`：左侧显示总差额与类别选择，右侧只显示当前类别；初始选择第一个未完成类别，帮助学生直接定位下一步。
- 类别选择使用 48dp 目标，支持 Tab、Enter/Space，并用方向键在类别间移动；选择后保留总览与返回路径。
- 切换类别仅使用一次淡入和轻微位移。`disableAnimations` 或减少动态开启时，持续时间和位移都归零。
- 页面级不出现横向滚动；360dp 下长类别、项目、等级和参与条件允许换行。
- 返回按钮、系统返回和“返回成绩单”使用同一返回结果，不新增第二套业务状态。

## 内容与异常状态

- `content`：展示总已获、总必修、差额、总体状态、所有类别和全部规则行。
- `empty`：保留标题、来源、时间和“返回成绩单”；正文仅说明“规则数据尚未同步，返回成绩单刷新后再查看”，不使用占满屏幕的巨大空态。
- `requiredCredit == null`：显示“必修要求未提供”，不按 0 处理，不绘制误导性完成比例。
- `earnedCredit == null`：显示“尚无已获记录”。
- `credit == null`：显示“积分待来源补全”。
- `passStatus` 为空：显示“状态未提供”，不根据数值自行判定通过。
- 非连续同类行按类别合并；可操作视图先展示未完成类别，未完成/已完成两组内部及项目明细保持源站首次出现顺序。重复规则行仍逐项展示，避免吞掉来源证据。

## 自评审记录

- 信息优先级：通过。首屏先给差额，未完成类别先于已通过类别；真实规则没有被三条抽象摘要替代。
- 密度：通过。去除了整页矩阵、横向滚动、多层卡框和重复标签；每个类别只保留一个结构标题。
- 操作协同：通过。类别选择、返回、来源信息共享同一上下文；切换不会清空总览或改变业务数据。
- 可访问性：通过设计检查。按钮目标为 48dp，选中状态有文字和语义，颜色不是唯一状态线索；后续由 Widget 测试核验键盘、语义和减少动态。
- 响应式：通过设计检查。360、768、1200、1600 四档分别采用连续账本或主从阅读，不依赖固定表格宽度。
- 非模板性复核：最初的“左侧深色百分比票面”只表达装饰性数字，且造成大片空白，已删除；改为源于成绩单语义的完成差额刻度。
- 截图复核修正：首轮 768dp 总分被差额文字挤成两行，已改为窄主从栏纵向排布；360dp 的多个类别卡已合并为单一连续账本，减少重复边框和卡间空白。
