## 任务与使用者

对象是需要快速判断当前学习状态、再进入成绩、考试或课表的在校学生。页面的单一任务是：在不改变任何教务数据的前提下，先建立“本学期—下一考试—可继续的学程”的阅读顺序，再提供详细来源。

## 设计方向

清源教务总览采用“连续学程流”，以事实卡片的自然内容高度替代装饰性的整行等高。其辨识点是把三项学期指标收束为一条可横向比较的账本，而把下一行动留给真实任务行；不以额外图表、渐变或空白填充制造层级。

## 冻结规则

- 小于 `breakpoint.medium` 时，标题只显示“学习进度”。它是完整名词短语，不得把“一处看全。”拆成孤字行；`medium` 及以上恢复“学习进度，一处看全。”。
- `medium` 及以上的两列卡片顶部对齐，但不得因同一行内较高的“学习档案”拉伸“完成度”；同样的自然高度规则适用于“下一场考试”。
- “查看详细数据源”是页内跳转，而不是与下方来源区无关的独立页尾操作。它与数据源标题之间只使用一个 `spacing.xl` 的阅读间隔。
- 窄屏继续按概览、考试、档案、完成度的单列顺序排列。所有现有 48dp 目标、键盘焦点、减少动态、刷新单飞和操作锁定语义不变。
- 不新增卡片、按钮、服务调用、设置项或视觉裸值；所有空间、颜色、字体和动效仍只来自清源 token。

## 方案比较与自评审

1. **保留等高网格**：否决。它在 768、1200 和 1600px 均将完成度卡拉到学习档案高度，视觉上产生大量无信息空框，与“按内容结束”的密度原则相悖。
2. **把完成度并入学习档案**：否决。完成度是培养进度事实，不是进入档案的动作；合并会模糊可点击行与只读指标的差别。
3. **同一阅读行、各自自然高度**：采用。保留横向扫描关系和现有任务入口，同时去除空白；顶部对齐使两块事实仍可一眼比较。
4. **通过缩小标题字号防止窄屏断词**：否决。会破坏全局字阶且仍不能保证短语完整。改为在窄屏使用语义完整的短标题。

## 实现与验收边界

本批仅调整总览标题、内容网格对齐方式、详细数据源的阅读间隔，以及相应 HTML 参考与测试。不得改动学期选择、数据计算、详情路由、来源刷新、缓存保留、错误恢复或操作锁定的业务契约。

人工核验覆盖 360×800、768×900、1200×900、1600×1000 的亮暗主题及 content、partial-error、operation-locked：确认无横向溢出、无孤字标题、无无信息等高空框、详细数据源连续可达，且锁定时详情入口仍不可操作。
