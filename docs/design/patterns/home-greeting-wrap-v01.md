## 用户与单一任务

对象是早晨打开首页、先判断今天课程和待办的学生。页面首要任务是让问候与日期瞬间可读，同时保留右侧 48dp 刷新操作；标题不能因为窄屏而把“今天”拆成孤字。

## 视觉方向

首页标题继续使用清源 MiSans `h1`、正文墨 `neutral.fg` 和日期的清源青 `brand.ink`。本批不加入新色、图标、卡片或按钮；唯一调整是把问候切为两个语言短语：

```text
360×800                         390+ / 768+
早上好，                         早上好，先看清今天。
先看清今天。                     [刷新]
[刷新]
```

在刷新按钮占据右侧空间时，两个短语按完整词组换行；空间足够时仍为一行。这个“呼吸断句”与当天计划的阅读节奏一致，而非用缩小字号回避布局问题。

## 响应式与交互

- 仅小于等于 420dp 的首页标题启用短语级换行；768/1200/1600 的标题内容、位置和操作排列不变。
- 两个短语均不可在内部换行，确保“今天。”不会成为独立一行；在 360dp 下稳定得到两行，在 390dp 或更宽空间允许同一行。
- 标题保留一个 `header` 语义节点和完整朗读文本“早上好，先看清今天。”；视觉拆分不得导致读屏器重复或省略内容。
- 刷新按钮保留当前 48dp 触控目标、状态锁和焦点顺序；不移动、不缩小，也不改变首页无滚动预算。
- 仅由布局重排触发既有页面 `motion.base`；减少动态时直接稳定在目标断行，没有单独的文字动画。

## 设计自评审

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| 缩小 360 标题字号 | 否决 | 会削弱首页信息层级，且在不同字重、字体渲染下仍可能出现不可控断行。 |
| 缩小或下移刷新按钮 | 否决 | 损失 48dp 命中区或让高频刷新脱离页面标题语境。 |
| 以完整阅读短语作为可换行单元 | 采用 | 在最窄视口消除“今 / 天”孤字，在中宽视口保持原有单行节奏，不增加任何视觉噪声。 |

## 验收条件

- 360×800 四种首页状态的亮暗主题中，问候只允许在“早上好，/先看清今天。”之间换行，不得在“今天”中间断行；首页仍不出现滚动。
- 390、768、1200、1600 宽度不会出现横向溢出，刷新目标的尺寸和语义不变。
- 标题的语义名称、刷新单飞锁、日期和状态药丸、键盘焦点及减少动态回归保持通过。
