# 安全与账户

## 用户任务

学生在同一处完成应用锁定、系统快速验证、校园服务凭据保存与验证，并能继续进入数据与隐私任务页。任何远端或本地存储失败都不得清空仍可编辑的输入和已有连接状态。

## 编排

1. 本地保护：密码保护、系统快速验证、修改密码和立即上锁形成一个操作上下文。
2. 教务凭据：先说明“仅保存在本机”，再提供保存和验证；学工号、OA、体育和邮箱凭据按依赖顺序排列。
3. 数据与隐私：只显示范围摘要和统一管理入口，高风险清除进入专用任务页。
4. 状态失败：在凭据标题前原位提示“无法读取本机凭据状态”，保留安全开关、输入框和已有文本，并提供 48dp 原位重试按钮。

## 响应式与密度

- 360–899：沿用设置分区抽屉；卡片单列滚动，保存/验证按钮可换行但不拉满整行，密码开关保持同行。
- 900–1199：顶部分区标签；凭据说明与动作在空间不足时上下排列。
- 1200 起：左侧设置导航；内容列封顶 768dp，表单封顶 560dp，不把字段和开关拉到窗口两端。
- 所有按钮和开关至少 48dp 命中区；输入失败不清空用户刚输入的内容。

## 动效与协同

- 保存和验证共享凭据操作锁，处理中禁用字段与重复动作；完成后只更新同一 service、账户和页面代次。
- 系统快速验证忙碌只在开关旁显示进度，不重排整卡。
- 减少动态时开关、卡片、按钮和状态提示即时切换。
