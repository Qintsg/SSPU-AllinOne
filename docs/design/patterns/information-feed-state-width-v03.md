## 场景与任务

当校园资讯尚未读取、正在读取、没有已认证来源或读取失败且没有缓存时，用户的唯一任务是理解原因并执行一次恢复操作。此时状态面板不是资讯列表，不应扩展到整个桌面内容列。

## 参考编排

```text
360px
┌──────────────────────────────┐
│ 图标 / 状态标题              │
│ 原因说明                     │
│ [唯一恢复行动，48dp]         │
└──────────────────────────────┘

768px 及以上
┌────────── 最多 560dp ──────────┐
│ 图标  状态标题与原因      [行动] │
└────────────────────────────────┘
```

## 冻结规则

- 360–767px 继续占满页面内容宽度，使用纵向图标、文案和行动，保留当前 5 个 `control.regular` 的可读高度。
- 768px 起面板最多为 `layout.formContentWidth`，与标题内容列左缘对齐；不得把短恢复信息拉满 `pageContentWidth`。
- initial、loading、empty、error 的标题、原因、活动环、按钮文字、主/次级按钮变体和回调均不变。加载继续没有按钮，错误继续提供“重试”，未认证继续进入“来源与认证设置”。
- 缓存可读但刷新失败仍使用 stale 内容态；本稿不得把它变为错误状态或丢失搜索、来源、筛选和分页上下文。
- 不增加新的卡片、来源、过滤器、网络请求、设置项或视觉裸值；状态切换只使用已有 `AnimatedSize` / token 动效并尊重减少动态。

## 自评审

1. **保留全宽横向状态卡**：否决。1200px 候选中，图标、两行文案和一个按钮只占左中右三处，边界中间没有信息，视觉上像未加载列表。
2. **在宽屏移除卡片**：否决。错误与未认证仍需要明确的焦点分组、恢复按钮和安全操作层级。
3. **收束为左锚定恢复列**：采用。它与页面标题形成同一阅读起点，行动仍在面板右侧，且把其余空间还给背景而非伪卡片。

## 验收边界

本批仅调整无内容资讯状态容器的断点宽度与对齐。覆盖四档亮暗 initial、loading、empty、error，并复核 stale 与筛选无结果不会受影响；重点检查 48dp 行动、键盘焦点、重试/来源设置回调和无横向溢出。
