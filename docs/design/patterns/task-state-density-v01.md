## 目标

快捷入口及教务成绩、考试、成绩处理等详情，在加载、空和错误时原先以固定高度卡片居中展示。短信息被拉成大面积空白，且“重试”离上下文过远。本稿将这些状态收束为保留来源与返回路径的任务账本，不增加业务请求、设置项或第二套状态。

## 视觉方向

- 延续清源的结构蓝、松石状态色、MiSans 与现有 `YhCard`，不引入新色、新图标或装饰插画。
- 状态的签名是“任务账本”：图标/活动环、标题、恢复说明和唯一动作按阅读顺序相邻，拒绝把短提示做成居中的全高海报。
- 宽屏状态卡宽度收束为 `layout.formContentWidth`；它与页面标题左缘对齐，而不是居中漂浮或撑满资料页。
- 卡片高度由内容和已有内边距决定。仅保证 48dp 操作目标，不以“填满首屏”为目的；页面底部的留白属于页面背景，不属于带边框的卡片。

## 响应式编排

```text
360 / 768                              1200 / 1600
┌ 页面标题与来源 ┐                     ┌ 页面标题、来源、筛选 ────────────┐
├ 状态账本（全宽）┤                   ├ 状态账本（表单宽、左锚定） ┐     │
│ 图标  标题      │                   │ 图标  标题                  │     │
│       恢复说明  │                   │       恢复说明 / 重试        │     │
│       [重试]    │                   └─────────────────────────────┘     │
└────────────────┘                   └───────────────────────────────────┘
```

- 360px：页面内边距保持当前 token；状态卡可占内容宽，标题和动作自然换行，最后一个操作不被底栏遮挡。
- 768px：不为短说明增加额外高度；卡片宽度随内容列扩展。
- 1200px 与 1600px：快捷入口状态和教务详情状态限制在 `layout.formContentWidth`，贴齐内容起点；筛选/来源行仍占原宽度，避免状态切换导致页面骨架跳动。
- `loading`：使用现有 `YhRing`，没有操作按钮；不显示骨架，不锁死返回。
- `empty`：明确“当前范围没有内容”，只在可重读时给出一个具体的“重新读取”动作。
- `error`：保留错误原因与重试；动作在说明之后，单飞期间由既有状态锁定。
- 减少动态时立刻完成布局变更；正常情况下仅使用 `motion.base` 的尺寸/透明度过渡。

## 范围与边界

本稿覆盖：

- `QuickLinksPage` 的 loading、empty、error。
- 教务成绩、考试、成绩处理、第二课堂成绩单与体育考勤详情共用的 `_AcademicDetailStateCard`。

不覆盖邮件正文：其现有正文卡由真实短正文和只读提示撑开，没有固定状态海报；不为“视觉一致”无故缩短可读正文。

保留现有 service、缓存、路由、筛选、单飞锁、错误文案和测试 fixture；只调整展示约束与状态对齐。

## 自评审

### 方案比较

1. **保留固定 344dp/384dp 最小高度**：否决。截图显示短提示周围存在大面积无信息的边框区域，违背状态应辅助恢复而不是占领页面的原则。
2. **移除所有卡片，改为裸文本**：否决。会削弱空/错误状态与背景内容、可点击区域之间的边界，也不利于键盘焦点和触控定位。
3. **收束为左锚定任务账本**：采用。卡片仍提供明确的任务边界，但尺寸由状态内容决定；宽屏不再把短文本误读为主内容。

### 核验清单

- 视口：360×800、768×900、1200×900、1600×1000；亮暗主题。
- 状态：快捷入口 loading/empty/error；三类教务详情 loading/empty/error/operation-locked。
- 操作：返回、筛选后空状态、重试、单飞锁、Tab/Shift+Tab、48dp 触控目标。
- 回归：无横向溢出、焦点可见、减弱动态、已有内容的 stale/partial-error 不被本稿改变。

## 实现界限

只使用已有清源 token，禁止新增裸像素视觉值或旧 Fluent/Material 成品控件。状态控件的动作、可用性和语义继续由现有页面状态决定。
