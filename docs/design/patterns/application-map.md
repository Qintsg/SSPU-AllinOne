# 全应用页面地图与页面契约

## 目标

本文件冻结清源 v0.3 的页面级信息架构。组件定义“一个控件如何工作”，本文件定义用户如何从打开应用走到一项真实校园任务。页面设计完成不等于 Flutter 页面已迁移；实现按这里的页面契约逐页替换历史 Fluent 视觉层。

可交互页面原型：[`samples/app-shell.html`](./samples/app-shell.html)。

## 全局框架

- 主目的地固定为：主页、教务、课表、信息、邮箱、跳转、设置。
- compact 只在底栏直接展示主页、教务、课表、信息和“更多”；邮箱、跳转、设置进入“更多”抽屉。
- medium 及以上展示完整 NavRail；expanded 可展开名称，但目的地顺序和用户可见名称不变。
- 每个页面头部依次放置场景眉题、任务标题、必要说明和最多一个主行动。刷新属于次要行动。
- 页面正文最大宽度 `1180dp`；桌面边距随窗口增长，compact 使用 `16dp`。
- Tabs、单选筛选与列表选择采用 roving focus：Tab 只进入当前项，方向键在组内移动并同步语义状态。
- 页面级行动必须给出可感知结果；原型使用 live status，Flutter 实现映射到 Semantics 通知和 Toast。

## 页面覆盖矩阵

| 页面 | 单一任务 | 首要内容 | 主行动 | 详情去向 |
|---|---|---|---|---|
| 主页 | 看清今天并决定下一步 | 今日学程时间轨 | 自定义首页 | 课程、校园卡、考勤、消息、邮箱 |
| 教务 | 核对学习进度 | 学期指标与下一场考试 | 刷新教务数据 | 成绩、过程分、考试、培养方案、体育考勤 |
| 课表 | 找到某天某节课程 | 周课表 / 按天列表 | 无；刷新为次要行动 | 课程详情、校历 |
| 信息 | 阅读与自己有关的校园消息 | 按来源筛选的信息流 | 无；刷新为次要行动 | 文章原文 / 外部网页 |
| 邮箱 | 浏览、阅读并主动发送学校邮件 | 收件箱列表 | 写邮件；刷新为次要行动 | 邮件详情 / 撰写邮件 |
| 跳转 | 找到一个校园外部入口 | 搜索与任务分组 | 无 | 外部网页确认页 |
| 设置 | 管理本地数据和外部连接 | 账户与连接状态 | 立即锁定 | 认证、通知、外观、隐私、关于 |

## 主页

首页把“校园时间”作为整套产品唯一高强度视觉。结构色背景承载日期、下一项和完整时间轨；其它概览卡保持纸面式中性表面。当前项使用青雾浅支，业务域色只出现在 44dp 服务图标容器中。

- compact：时间轨在前，概览卡在后，均为单列。
- medium：时间轨与概览仍上下排列，概览可两列。
- expanded：时间轨与概览按约 `1.65 : .8` 并列。
- 时间、地点、来源和刷新时刻均使用真实任务文案，不显示缓存键或接口名。

## 教务

教务页用“概览—即将发生—学习档案—完成度”组织只读信息。成绩、排名等数字用等宽字体；“只读访问”和 OA 登录状态在内容之前明确展示。

- 未登录时不展示伪造的零分数据，改为说明连接需求和“前往设置”。
- 详情页必须保留学期筛选、数据来源、更新时间和返回后的滚动上下文。
- 状态色表达成功、警告、失败；教务蓝只表达来源域。

## 课表

桌面使用周视图维持课程的横纵空间关系；compact 用日期 Tabs 选择一天，再按时间顺序展示 CourseBlock。课程块使用低饱和业务域 tint 整块着色，正文保持高对比。

- 横向滚动容器必须有可访问名称和键盘焦点。
- 当前日期、当前节次与临时调课分别表达，不能只靠颜色区分。
- 无课程时显示“今天没有课程”，同时保留切换日期和查看校历的入口。

## 信息

信息页先展示来源与时间，再展示标题和两行摘要。桌面左侧保留来源筛选；compact 将筛选折叠到横向 Chips。文章详情优先内部阅读，必须跳转外部时显示目标域名。

- 刷新期间保留已有内容并显示进度，不用整页骨架替换。
- 来源徽标使用业务域色；已读/未读通过字重和语义文本共同表达。
- 空状态分别说明“尚未认证”和“当前筛选没有结果”。

## 邮箱

expanded 使用列表—详情并列；compact 和 medium 使用列表进入独立详情页。列表项包含发件人、主题、时间和一行预览，不直接渲染不可信 HTML。

- 连接状态、可证实的邮件数量和最后同步时间位于列表之前；服务未提供已读字段时不得推断未读数。
- 认证失败时保留已有本地邮件并明确其缓存时间。
- 附件、外部链接和远程图片必须在用户触发后处理。
- 写邮件进入独立撰写状态；只提交普通文本，不保存草稿、不后台重试，发送中锁定字段并保留可感知结果。

## 快速跳转

入口按“学习与教务、校园服务、学校信息”分组，并支持按用户能识别的任务名称搜索。每个入口在名称后说明用途，外部跳转使用一致的箭头提示。

- 搜索结果保留原分组名称。
- 无匹配结果时说明可用关键词并提供“清除搜索”，不留下空白分组。
- 配置加载失败时说明配置位置和重试动作，不展示空白页。
- 打开需要认证的入口前先判断现有登录态，避免无意义重定向。

## 设置

设置以“账户与连接、首页与通知、外观、数据与隐私、关于”分区。每一行先呈现当前状态，再呈现管理动作；高风险的清除数据与普通开关分开。

- compact / medium 使用单行可横向滚动的设置分区 Tabs，避免分区导航占据首屏；expanded 使用纵向分区导航。
- 切换分区时同步页面任务标题、说明、`aria-selected` 和可见面板，不只替换选中颜色。
- 凭据只描述存储位置和连接结果，不显示原文。
- “立即锁定”名称在按钮、结果提示和后续锁屏页中保持一致。
- 清除本地数据必须经过确认 Dialog，并逐项列出会删除与会保留的内容。

## 详情与返回

- 详情页使用 AppBar 返回槽位；桌面可以在主内容区内推入，compact 使用完整页面路由。
- 从列表进入详情再返回时，恢复筛选、滚动位置和已加载数据。
- 外部网页、PDF 和认证 WebView 都是明确的边界页面，标题显示目标名称，并提供关闭/返回与来源说明。

## 页面级完成定义

- 七个主目的地均有任务、编排、响应式、状态和详情契约。
- 页面原型可在 360、768、1200、1600px 查看，支持亮暗主题和键盘操作。
- 原型不得出现水平页面溢出、不可见焦点、低于 48dp 的主导航目标或无标签交互控件。
- 机器校验覆盖页面索引、原型文件、导航目的地和禁用的旧设计值。
