## 目标

360px 窄屏的“本学期概览”只包含平均绩点、已获学分和已读成绩三个短指标，却将每项纵向拉成大块，导致首屏无法同时看到下一场考试和学习档案入口。本稿只改变指标的紧凑编排，不改变数值、来源或详情路由。

## 参考编排

```text
compact
+---------------------------------------+
| 本学期概览                            |
| 2025-2026 学年夏季学期                |
| +-----------+ +-----------+ +--------+ |
| | 平均绩点   | | 已获学分   | | 已读成绩 | |
| | 4.00      | | 86.0      | | 3 门    | |
| +-----------+ +-----------+ +--------+ |
+---------------------------------------+

medium / expanded
三个指标继续横向等分，保持原有高度与对齐。
```

## 布局契约

- compact 指标使用单行三列，单项保留至少一个 `control.regular` 的触控安全高度，但不伪装成可点击卡片。
- 指标标签和值保持完整，不使用省略号；数值继续使用等宽数字和原有语义。
- 768px 及以上保持既有横向三列，不改变宽屏的比较关系。
- 颜色、圆角、间距和动效只引用清源 token；指标不增加独立按钮或重复边框。
- 360×800 亮暗主题下，概览卡收束后应能看到下一场考试或学习档案的标题，页面仍允许业务内容继续向下滚动。

## 自评审

### 方案比较

1. **继续纵向三块指标**：否决。短字段占据过多垂直空间，信息比较效率最低。
2. **改成三张可点击卡片**：否决。指标本身没有独立动作，会增加不必要的按钮边界和误导性。
3. **共享概览卡内的紧凑三列账本**：采用。保留原有视觉层级与来源语义，减少空白且不改变业务行为。

### 核验清单

- 视口：360×800、768×900、1200×900、1600×1000。
- 主题：亮色、暗色。
- 数据：完整值、缺失值、部分失败和操作锁定。
- 交互：刷新锁定、详情入口、键盘焦点和减少动态。
- 约束：无横向溢出；指标不被截字；宽屏比例不发生回归。

## 实现边界

只修改 `_AcademicOverviewCard` 与 `_AcademicMetricBox` 的展示布局和对应测试，不改变教务服务、缓存、学期选择或详情导航。
