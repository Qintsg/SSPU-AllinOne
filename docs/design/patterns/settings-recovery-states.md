# 设置恢复状态

## 用户任务

数据与隐私、应用更新和微信公众号认证在读取、执行或失败时，必须保留当前页面框架、已有结果和仍可执行的恢复动作。状态卡只包裹真实任务内容，不填满剩余窗口制造空白。

## 共同编排

- 标题、来源和主要动作始终保持同一位置，避免状态切换导致视线跳跃。
- loading 使用警告色原位提示“正在恢复”，并锁定重复动作；已有设置行继续可读。
- error 使用危险色说明失败范围；已完成项与未完成项分开，恢复动作靠近对应行。
- content 的行按钮使用具体动词：清除、断开、查看、切换、重新认证、重新校验。
- 1200 起状态卡按内容高度收束；360/768 允许页面自然滚动，底部导航不覆盖最后一个可操作目标。

## 页面差异

- 数据与隐私：三行分别管理缓存、账户连接与隐私说明；危险操作仍进入二次确认流程。
- 应用更新：未检查时显示版本、通道与自动检查状态；完成后原位增加结果摘要，不新建第二张大卡。
- 微信认证：未连接时保留明确开始动作；连接或失败时显示三步认证账本，并区分重新认证与重新校验。
