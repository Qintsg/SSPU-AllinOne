# 校园资讯流

## 用户任务

学生需要快速判断资讯来自哪里、何时更新，并在一屏内完成搜索、来源切换和进入高级筛选；网络异常时继续阅读缓存内容，而不是被整页错误打断。

## 视觉方向

- 颜色继续使用清源结构蓝、松石青与中性色 token，不为资讯页引入独立装饰色。
- 标题承担编辑式信息层级；来源药丸与更新时间形成“来源—时间”签名，不使用通用统计大卡或装饰数字。
- 1200 起采用“来源窄列 + 资讯主列”，两列内容底边尽量收束，避免来源卡拉满整行或把文章卡片撑得过宽。
- 360–900 使用单行来源条；360 将“筛选”固定在右侧，来源在剩余空间横向滚动，保证高级筛选无需猜测或滚到末尾。

## 响应式编排

```text
360                    768                     1200+
┌ 标题       刷新 ┐    ┌ 标题       刷新 ┐     ┌ 标题          刷新 ┐
├ 来源/数量/时间 ┤    ├ 来源/数量/时间 ┤     ├ 来源/数量/时间  ┤
├ 搜索           ┤    ├ 搜索           ┤     ├ 搜索              ┤
├ 来源滚动 | 筛选 ┤    ├ 全部来源 | 筛选 ┤     ├ 来源窄列 | 资讯主列 ┤
├ 资讯卡         ┤    ├ 资讯卡         ┤     └───────────────────┘
└ 底部主导航     ┘    └ 紧凑侧栏       ┘
```

## 状态与协同

- `initial`：说明先读本机缓存，主动作是“读取校园资讯”。
- `loading`：显示局部活动环，禁用重复刷新，不制造整页骨架闪烁。
- `content`：搜索、来源切换、高级筛选和分页共同作用于同一份展示状态。
- `empty`：区分“没有认证来源”与“筛选无结果”；前者进入来源设置，后者清除筛选。
- `stale`：保留资讯、筛选和搜索，在内容上方提示缓存时间与手动刷新方式。
- `error`：没有缓存时给出重试；有缓存的失败进入 `stale`，不得清空可读内容。
- 搜索词、来源和高级筛选统一生成活动条件；清除操作只清除筛选，不改变来源认证或缓存。

## 动效与无障碍

- 页面进入与筛选反馈使用清源快速动效；减少动态时即时切换。
- 来源条支持方向键漫游，搜索和筛选保持可见焦点；触控目标不小于 48dp。
- 刷新按钮忙碌期间不可重复触发；筛选关闭后焦点归还触发器。
