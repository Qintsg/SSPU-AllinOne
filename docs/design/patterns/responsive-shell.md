# 响应式导航壳

## 用户任务

用户在手机、平板和桌面上都能确认当前位置，并以一致名称到达主页、教务、课表、资讯、邮箱和设置。

## 编排

- `< 768dp`：BottomNav 展示 3–5 个首要目的地，其余进入“更多”。
- `>= 768dp`：NavRail 展示同一目的地集合；桌面可附加自绘窗口框架。
- 内容在 600/768/1200/1600dp 断点调整边距与列数，不改变业务状态。
- 鼠标提供 hover，键盘提供可见焦点和方向键导航，触控保持 48dp 最小目标。

## 验收

- 当前项、徽标与语义标签跨形态一致。
- 安全区、输入法与桌面窗口按钮不遮挡内容。
- 减少动态时导航切换不发生位移或缩放动画。
