# 开源许可密度 v01

## 目标

开源许可页的任务是让学生按项目核对使用场景和许可边界，并能安全打开项目链接。窄屏用连续项目卡保证阅读；宽屏使用四列表格快速比较。表格的实际列宽已被内容确定，外层表面不能再为填满页面制造空白边框。

## 视觉方向

- 沿用清源表格、服务色链接、来源条、MiSans 和现有外链确认；不更换许可证信息、项目名称或打开行为。
- 本批签名是“边界即表格”：宽屏外卡恰好包住四列许可矩阵，左锚定标题与来源；右侧留白回归页面背景。
- 窄屏保持逐项目卡片，避免把四列强塞进横向表格或改变外部链接的触控目标。

## 响应式编排

```text
360 / 768                              1200 / 1600
┌ 标题、来源、返回 ┐                   ┌ 标题、来源、返回 ────────────┐
├ 项目卡               ┤                ├ 四列许可矩阵（内容宽）┐      │
├ 项目卡               ┤                │ 项目 | 场景 | 许可证 | 说明 │      │
└ …                    ┘                └──────────────────────────┘      │
```

- 360px：每个项目卡保留项目链接、使用场景、许可证和说明；页面自然滚动，底栏不遮挡下一项。
- 768px：当内容区不足表格可读宽度时继续使用卡片，不触发被截断的横向矩阵。
- 1200px 与 1600px：表格外卡限制为四列内容总宽及边框，左锚定；无信息右侧不显示为卡片内部。
- external-confirmation / external-cancelled / external-error / operation-locked：横幅、焦点、锁和列表内容按现有行为保持；容器宽度不因状态改变。

## 范围与边界

覆盖 `OpenSourceLicensesPage` 宽屏 `_OpenSourceProjectsView` 的表格容器宽度。

不覆盖项目清单、许可证文本、外链确认、浏览器打开、单飞锁、移动项目卡、表格列语义或服务层。保留 48dp 目标、键鼠访问和已读位置恢复。

## 自评审

1. **维持全宽外卡**：否决。1200/1600 候选中，四列矩阵结束后仍有被边框包围的大片空白，和表格的比较任务无关。
2. **把宽屏也改成卡片流**：否决。会丢失使用场景、许可证和说明的横向比较能力。
3. **表格容器收束到列总宽**：采用。保留宽屏比较与窄屏阅读两种最佳模式，视觉边界精确表达表格范围。

## 核验清单

- 视口：360×800、768×900、1200×900、1600×1000；亮暗主题。
- 状态：content、external-confirmation、external-cancelled、external-error、operation-locked。
- 操作：打开项目、取消/确认外部打开、错误恢复、返回关于、Tab/Shift+Tab/Escape。
- 可访问性：项目链接语义、48dp 触控目标、表格在宽屏可读、移动端无横向溢出、焦点归还与减少动态。

## 实现界限

仅按已有 token 计算矩阵宽度并限制外卡。禁止更改项目数据、增加裸视觉值或以截图理由删除外部打开安全边界。
