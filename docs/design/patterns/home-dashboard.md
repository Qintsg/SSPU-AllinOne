# 首页与今日学程时间轨

## 用户任务

学生打开应用后，先确认今天的课程、待办与校园服务状态，再进入某个业务域查看详情。

## 视觉签名

首页以“今日学程时间轨”组织当天课程、考试、待办和刷新时间。墨蓝时间轴承担结构，青雾只标记当前项或可执行行动；业务域色用于来源识别，不作为大面积装饰。

## 编排

1. TodayCard：日期、当前节次、下一事项和今日负荷；高度受当前视口约束，不按内容无限增长。
2. 只读概览：课程、校园卡、体育、第二课堂、消息等按用户配置排列。相邻的同层摘要共用一个概览面板和内部分隔线，不为每一项重复套独立大卡片。
3. 状态反馈：加载、未配置、缓存过期、失败和空状态均保留下一步指引。
4. 校园卡详情：余额与卡状态固定在交易筛选之前；日期错误保留上一次有效记录，空结果不清除余额。
5. 常用入口：与第二课堂共用一个轻量行动坞，只保留一层外框和内部结构分隔。入口保持 48dp 命中区域，默认无独立描边，仅在 hover、焦点和按压时显示青雾反馈；紧凑端使用语义完整的图标操作，不使用占满整行的大按钮。

## 响应式与密度

- compact（360×800 起）：默认文字缩放下整页不滚动。标题区、状态、时间轨、2×2 概览面板和行动坞共同适配可用高度；时间轨仍保持线性阅读，但行高、标题字号和装饰留白收敛。超过 1.2 倍文字缩放时允许纵向滚动，不能裁字。
- medium（768×900 起）：时间轨与统一概览面板保持双栏，行动坞跨满底部；不得因为宽度不足 900dp 就把所有摘要堆到时间轨下方。
- expanded（1200×900 起）：主轨与业务概览保持约 3:2 权重，主区高度约为视口的 42%，并限制在 372–420dp；各区按内容从顶部连续排布，底部行动坞只按内容占高。
- large（1600×1000 起）：增加可读宽度而非同比放大卡片、按钮和留白；主标题封顶于 display 字号，时间轨行高封顶 60dp，概览行高不随窗口无限增长。
- 横屏和低高度窗口按“可用高度”共同选择密度，不能只根据宽度判断布局。

### 首屏高度预算（默认文字缩放）

| 区域 | compact 360×800 | medium 768×900 | expanded 1200×900+ |
|---|---:|---:|---:|
| 标题 + 状态 | ≤ 126dp | ≤ 132dp | ≤ 132dp |
| 时间轨 | 270–310dp | 372–378dp | 372–420dp |
| 概览 | 2×2，共 ≤ 136dp | 与时间轨等高 | 与时间轨等高 |
| 行动坞 | ≤ 68dp | ≤ 88dp | ≤ 88dp |

## 动效

- 数据值换代使用 120–200ms 交叉淡入和最多 8dp 的位移；整张卡片不因刷新上下跳动。
- 刷新按钮在操作期间持续旋转，完成后在原位置停下；重复触发由同一操作锁拒绝。
- 概览项 hover、焦点和按压只改变边框、底色和 0–1 级阴影，120ms 完成。
- 断点切换不播放大范围位移动画；可在 200ms 内交叉淡入新编排。系统“减少动态”开启时全部收敛为即时状态切换。

## 验收

- 不改变现有服务层、缓存策略或只读约束。
- 亮暗主题、360×800、768×900、1200×900、1600×1000、键盘与语义测试覆盖。
- 默认文字缩放下四档内容截图不得出现主页滚动条或底部内容被导航遮挡。
- 时间轨结构面上的主标题和当前事项在亮暗主题都使用 `onStructural`；事项只用字重强调，不能使用暗色主题下的深色 tint。
- 概览面板不存在为了等高而产生的大片空白；视觉按钮外框不得大于其内容所需宽度。
- 首页现有业务回归测试继续通过。
- 部分来源失败、缺少部分凭据和刷新操作锁定均保留有效时间轨、概览与行动坞；只替换状态提示，不清空已有内容。
- 首页显示设置保留现有 8 项独立存储与切换语义；允许重新分组和改名，但不得用组合开关降低可配置粒度。
