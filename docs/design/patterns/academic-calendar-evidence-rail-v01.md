# 校历证据栏密度 v01

## 目标

校历页服务于需要确认查询学期、校历来源和原始 PDF 的学生。宽屏左侧的来源、学期选择和学期边界组成“证据栏”；右侧保留可沉浸阅读的 PDF 外部正文。证据栏的短事实卡不能为了匹配 PDF 高度而被拉成大空框。

## 视觉方向

- 延续清源的学术服务色、结构化来源条、MiSans 和现有 `Yh*` 控件；不改动 PDF 外部区域、工具栏、正文 placeholder 或 sidecar 边界。
- 本批签名是“内容高证据栏”：左侧每张卡只包围对应事实；右侧 PDF 作为独立阅读面板占用剩余空间，两者不再错误地共享高度。
- 宽屏留白属于证据栏背景，帮助区分“可操作的学期设置”和“原始 PDF”；不会以更多卡片或装饰填补空白。

## 响应式编排

```text
360 / 768                              1200 / 1600
┌ 学年横向选择 ┐                       ┌ 来源 / 查询 / 学年 / 证据 ┐ ┌ 原始 PDF ┐
├ 查询学期     ┤                       │ 每张卡按内容结束           │ │ 外部正文 │
├ 学期边界     ┤                       └────────────────────────────┘ │ 填充阅读 │
├ 原始 PDF     ┤                                                     └──────────┘
└ 外部正文     ┘
```

- 360px：保持现有纵向顺序与 PDF 面板占位；学期选择、边界、刷新和专注查看无裁切。
- 768px：保持当前两区过渡和紧凑状态横幅；不为对齐而引入嵌套滚动。
- 1200px 与 1600px：证据栏顶部对齐，来源、统一查询、学年选择和边界卡按内容高度结束；下方是页面背景。PDF 继续填充右侧可阅读区域。
- loading / stale / partial-error / operation-locked：继续保留当前学期、PDF 和返回路径。状态横幅不改变证据栏的内容高度规则。
- PDF loading / empty / error / external-confirmation：由专用 PDF 框架继续负责；其大正文区是外部内容边界，不属于本稿的卡片空白。

## 范围与边界

覆盖 `AcademicCalendarPage` 宽屏布局中 `_CalendarEvidence` 的垂直约束。

不覆盖校历服务、学年/学期保存、PDF 渲染、外部打开、下载、来源文本、状态文案、侧栏宽度或紧凑端布局。保留既有键盘、触控、刷新单飞、失败恢复和外部区域声明。

## 自评审

1. **保持证据卡与 PDF 等高**：否决。1200px 候选中，边界事实只使用卡片顶部，空白边框让人误以为还有未加载数据。
2. **让证据栏滚动或填充更多摘要**：否决。会打断查询与 PDF 的连续比较，并引入无业务价值的内容。
3. **证据卡内容高、PDF 保持独立填充**：采用。左右职责清楚，短事实不被稀释，外部文档仍有足够阅读面积。

## 核验清单

- 视口：360×800、768×900、1200×900、1600×1000；亮暗主题。
- 状态：校历 loading/content/empty/stale/error/partial-error/operation-locked/external-confirmation/external-error；PDF loading/content/empty/error/external-confirmation。
- 操作：学年选择、查询学期、刷新、专注查看、PDF 下载/外部打开、取消、重试与返回。
- 可访问性：48dp 目标、无横向溢出、窄屏阅读顺序、焦点可见、减少动态、外部正文边界不被误判为清源卡片。

## 实现界限

仅删除证据卡的等高约束并补充回归证据。禁止改变数据请求、PDF 外部区域、路由、操作锁、现有 token 或业务状态。
